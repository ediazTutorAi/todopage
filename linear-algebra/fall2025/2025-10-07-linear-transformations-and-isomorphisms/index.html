Linear Transformations and Isomorphisms

MATH 3330 · Dr. Esteban Diaz
Definition 4.2.1
Linear transformations, image, kernel, rank, nullity

Let \(V\) and \(W\) be linear spaces. A function \(T\) from \(V\) to \(W\) is a linear transformation if for all \(f,g\) in \(V\) and all scalars \(k\)

$$T(f+g)=T(f)+T(g)\qquad\text{and}\qquad T(kf)=kT(f).$$

Its image and kernel are \(\operatorname{im}(T)=\{T(f):f\in V\}\) (a subspace of \(W\)) and \(\ker(T)=\{f\in V:T(f)=0\}\) (a subspace of \(V\)). If they are finite dimensional, \(\operatorname{rank}(T)=\dim(\operatorname{im}T)\) and \(\operatorname{nullity}(T)=\dim(\ker T)\), and for finite dimensional \(V\) the rank-nullity theorem holds:

$$\dim(V)=\operatorname{rank}(T)+\operatorname{nullity}(T).$$

Example 1. \(D(f)=f'\) from \(C^\infty\) to \(C^\infty\) (the smooth functions).

Is \(D\) linear?Yes: \((f+g)'=f'+g'\) and \((kf)'=kf'\), the rules of calculus.
\(\ker(D)\)\(f'=0\) means \(f\) is constant. A basis is \(f(x)=1\), so the nullity is 1.
\(\operatorname{im}(D)\)Every smooth \(g\) has an antiderivative (fundamental theorem of calculus), so \(\operatorname{im}(D)=C^\infty\).
Examples 2 and 3
An integral and a shift: kernel and image

Example 2. Let \(C[0,1]\) be the continuous functions on \([0,1]\), and \(I(f)=\displaystyle\int_0^1 f(x)\,dx\) from \(C[0,1]\) to \(\mathbb{R}\).

Why is \(I\) linear?\(\int_0^1(f+g)=\int_0^1 f+\int_0^1 g\) and \(\int_0^1 kf=k\int_0^1 f\)
\(\operatorname{im}(I)\)Any real \(b\) equals \(I(f)\) for the constant function \(f(x)=b\). So \(\operatorname{im}(I)=\mathbb{R}\) and \(\operatorname{rank}(I)=1\).
Name a nonzero element of \(\ker(I)\)\(f(x)=x-\tfrac12\), since \(\int_0^1(x-\tfrac12)\,dx=0\). The kernel is infinite dimensional.

Example 3. Let \(V\) be all infinite sequences, and \(T(x_0,x_1,x_2,\dots)=(x_1,x_2,x_3,\dots)\) from \(V\) to \(V\) (drop the first term). It is linear.

\(\ker(T)\)All sequences \((x_0,0,0,\dots)\) with \(x_0\) arbitrary. A basis is \((1,0,0,\dots)\), so the nullity is 1.
Is \((1,2,3,\dots)\) in the image?Yes: \(T(0,1,2,3,\dots)=(1,2,3,\dots)\). The first term \(x_0\) is free, so choose \(0\).
\(\operatorname{im}(T)\)Every sequence: \((b_0,b_1,\dots)=T(0,b_0,b_1,\dots)\). So \(\operatorname{im}(T)=V\).

Here \(T\) has a nonzero kernel and its image is everything. That cannot happen for a map from \(\mathbb{R}^n\) to \(\mathbb{R}^n\), but it happens on infinite dimensional spaces.

Isomorphisms
Definition 4.2.2 and Theorem 4.2.3: coordinates are isomorphisms

An invertible linear transformation \(T\) is called an isomorphism. The linear space \(V\) is isomorphic to \(W\) if there exists an isomorphism \(T\) from \(V\) to \(W\).

Example 4. \(L\!\left(\begin{bmatrix}a&b\\c&d\end{bmatrix}\right)=\begin{bmatrix}a\\b\\c\\d\end{bmatrix}\) from \(\mathbb{R}^{2\times2}\) to \(\mathbb{R}^4\) just rearranges four scalars. It is linear, and \(L^{-1}\) puts them back, so \(\mathbb{R}^{2\times2}\cong\mathbb{R}^4\).

Theorem 4.2.3. If \(\mathfrak{B}=(f_1,\dots,f_n)\) is a basis of \(V\), then the coordinate transformation \(L_{\mathfrak{B}}(f)=[f]_{\mathfrak{B}}\) from \(V\) to \(\mathbb{R}^n\) is an isomorphism. Every \(n\)-dimensional space is isomorphic to \(\mathbb{R}^n\).

$$f=c_1f_1+\cdots+c_nf_n\ \text{ in }V\ \ \underset{L_{\mathfrak{B}}^{-1}}{\overset{L_{\mathfrak{B}}}{\rightleftarrows}}\ \ [f]_{\mathfrak{B}}=\begin{bmatrix}c_1\\\vdots\\c_n\end{bmatrix}\ \text{ in }\mathbb{R}^n$$
What is \([f]_{\mathfrak{B}}\) for \(f=2-x+3x^2\) in \(P_2\), \(\mathfrak{B}=(1,x,x^2)\)?\(\begin{bmatrix}2\\-1\\3\end{bmatrix}\)
Why can we use Chapters 1 to 3 on \(P_2\)?Because \(L_{\mathfrak{B}}\) is linear and invertible: sums go to sums, scalar multiples to scalar multiples, so any question about \(P_2\) can be moved to \(\mathbb{R}^3\) and back.
Example 5, Part 1
\(T(A)=S^{-1}AS\) is linear

Show that the transformation \(T(A)=S^{-1}AS\) from \(\mathbb{R}^{2\times2}\) to \(\mathbb{R}^{2\times2}\) is an isomorphism, where \(S=\begin{bmatrix}1&2\\3&4\end{bmatrix}\).

Definition 4.2.2 asks for two things(1) \(T\) is a linear transformation, and (2) \(T\) is invertible. We check them separately.
Rule 1: \(T(A_1+A_2)=T(A_1)+T(A_2)\)Matrix multiplication distributes over addition, so \(T(A_1+A_2)=S^{-1}(A_1+A_2)S=S^{-1}A_1S+S^{-1}A_2S=T(A_1)+T(A_2)\).
Rule 2: \(T(kA)=kT(A)\)A scalar moves freely through a matrix product, so \(T(kA)=S^{-1}(kA)S=k\,S^{-1}AS=kT(A)\).
Does the particular \(S\) matter for linearity?No. The two computations work for any fixed \(S\) (we only need \(S^{-1}\) to exist, which is used in part 2). Linearity comes from the shape \(A\mapsto(\text{matrix})\,A\,(\text{matrix})\).

Next slide: invertibility. The most direct way to show a function is invertible is to write down its inverse.

Example 5, Part 2
\(T(A)=S^{-1}AS\) is invertible
Find \(S^{-1}\) first\(\det S=1\cdot4-2\cdot3=-2\neq0\), so \(S^{-1}=\dfrac{1}{-2}\begin{bmatrix}4&-2\\-3&1\end{bmatrix}=\begin{bmatrix}-2&1\\ \tfrac32&-\tfrac12\end{bmatrix}\). (This is why \(T\) is defined at all.)
Solve \(B=S^{-1}AS\) for \(A\)Multiply on the left by \(S\): \(SB=AS\). Multiply on the right by \(S^{-1}\): \(A=SBS^{-1}\).
Candidate inverse\(T^{-1}(B)=SBS^{-1}\). For every \(B\) there is exactly one \(A\), so \(T\) is invertible.
Verify both compositions\(T^{-1}(T(A))=S(S^{-1}AS)S^{-1}=A\) and \(T(T^{-1}(B))=S^{-1}(SBS^{-1})S=B\).
Example with numbers: \(A=\begin{bmatrix}1&0\\0&0\end{bmatrix}\)\(AS=\begin{bmatrix}1&2\\0&0\end{bmatrix}\), so \(T(A)=S^{-1}(AS)=\begin{bmatrix}-2&-4\\ \tfrac32&3\end{bmatrix}\). Undo it: \(S\,T(A)\,S^{-1}=\begin{bmatrix}1&0\\0&0\end{bmatrix}=A\).
A second proof, with the kernelIf \(T(A)=0\) then \(S^{-1}AS=0\), and multiplying by \(S\) and \(S^{-1}\) gives \(A=0\). So \(\ker(T)=\{0\}\), and since the domain and target both have dimension 4, Theorem 4.2.4(c) (next slide) says \(T\) is an isomorphism.
Conclusion\(T\) is linear and invertible, hence an isomorphism. Matrices \(A\) and \(S^{-1}AS\) are similar, so this map is "change the basis" acting on all \(2\times2\) matrices at once.
Theorem 4.2.4
Properties of isomorphisms

Let \(T\) be a linear transformation from \(V\) to \(W\).

  1. \(T\) is an isomorphism if (and only if) \(\ker(T)=\{0\}\) and \(\operatorname{im}(T)=W\).

In parts b to d, \(V\) and \(W\) are finite dimensional.

  1. \(V\) is isomorphic to \(W\) if (and only if) \(\dim(V)=\dim(W)\).
  2. If \(\ker(T)=\{0\}\) and \(\dim(V)=\dim(W)\), then \(T\) is an isomorphism.
  3. If \(\operatorname{im}(T)=W\) and \(\dim(V)=\dim(W)\), then \(T\) is an isomorphism.
Why does (a) hold?\(\operatorname{im}(T)=W\) says \(T(f)=g\) always has a solution. If \(T(f_1)=T(f_2)=g\), then \(T(f_1-f_2)=0\), so \(f_1=f_2\) when the kernel is \(\{0\}\): the solution is unique, hence \(T\) is invertible.
Why does (c) hold?Rank-nullity: \(\dim(V)=0+\dim(\operatorname{im}T)\), so \(\dim(\operatorname{im}T)=\dim(W)\), and a subspace of \(W\) of full dimension is \(W\) itself. Then use (a).
Is \(P_2\) isomorphic to \(\mathbb{R}^{2\times2}\)? To \(\mathbb{R}^3\)?\(\dim P_2=3\), \(\dim\mathbb{R}^{2\times2}=4\): no. \(\dim\mathbb{R}^3=3\): yes, by (b).

Warning: equal dimensions alone do not make a given \(T\) an isomorphism. Part (c) needs the kernel too.

Example 6
Evaluating a polynomial at three points: two nearly identical maps

Consider \(f\mapsto\begin{bmatrix}f(1)\\f(2)\\f(3)\end{bmatrix}\) in two settings: (a) from \(P_3\) to \(\mathbb{R}^3\), and (b) from \(P_2\) to \(\mathbb{R}^3\). Which is an isomorphism? Call the maps \(L\) and \(T\).

(a) \(L:P_3\to\mathbb{R}^3\).

Dimensions\(\dim P_3=4\) (basis \(1,x,x^2,x^3\)) and \(\dim\mathbb{R}^3=3\).
Apply Theorem 4.2.4(b)Isomorphic spaces must have equal dimensions. \(4\neq3\), so \(P_3\) and \(\mathbb{R}^3\) are not isomorphic, and \(L\) is not an isomorphism.
Where does it fail, concretely?With \(f=a+bx+cx^2+dx^3\), \(L(f)=\begin{bmatrix}a+b+c+d\\a+2b+4c+8d\\a+3b+9c+27d\end{bmatrix}\): 3 equations in 4 unknowns, so a nonzero solution of \(L(f)=0\) must exist (the kernel is not \(\{0\}\)).
Name one\(f(x)=(x-1)(x-2)(x-3)=x^3-6x^2+11x-6\). Check: \(f(1)=f(2)=f(3)=0\) but \(f\neq0\).
Rank-nullity agrees\(\operatorname{rank}(L)\le3\), so \(\operatorname{nullity}(L)=4-\operatorname{rank}(L)\ge1\).

(b) \(T:P_2\to\mathbb{R}^3\), the same formula on quadratics.

Dimensions\(\dim P_2=3=\dim\mathbb{R}^3\). The dimension test passes, but this alone does not show \(T\) is an isomorphism.
Find \(\ker(T)\)\(T(f)=0\) means \(f(1)=f(2)=f(3)=0\): the quadratic \(f\) has three zeros.
Why is \(f=0\)?A nonzero polynomial of degree at most 2 has at most 2 roots. Three roots force \(f=0\). So \(\ker(T)=\{0\}\).
Conclude with Theorem 4.2.4(c)\(\ker(T)=\{0\}\) and \(\dim P_2=\dim\mathbb{R}^3\), so \(T\) is an isomorphism.
Second proof with a matrixIn coordinates \(f=a+bx+cx^2\), \(T(f)=\begin{bmatrix}1&1&1\\1&2&4\\1&3&9\end{bmatrix}\begin{bmatrix}a\\b\\c\end{bmatrix}\), and the determinant is \(1(18-12)-1(9-4)+1(3-2)=2\neq0\). The matrix is invertible, so \(T\) is too.
What does it mean?Any three values \(f(1),f(2),f(3)\) come from exactly one quadratic: through three points with distinct \(x\) there is a unique parabola.

Summary
The one-page version
Linear transformation\(T(f+g)=T(f)+T(g)\), \(T(kf)=kT(f)\); \(\operatorname{im}(T)\subseteq W\) and \(\ker(T)\subseteq V\) are subspaces; \(\dim V=\operatorname{rank}+\operatorname{nullity}\)
Isomorphisman invertible linear transformation; \(V\cong W\) means same structure
Coordinates\(L_{\mathfrak{B}}:V\to\mathbb{R}^n\) is an isomorphism, so every \(n\)-dimensional space is isomorphic to \(\mathbb{R}^n\)
Is \(T\) an isomorphism?(1) \(\dim V=\dim W\)? If not, no. (2) Write the inverse? If so, yes. (3) Otherwise: is \(\ker(T)=\{0\}\) (or \(\operatorname{im}T=W\))? With equal dimensions either one is enough.
Infinite dimensionsthe shortcuts in (2) and (3) fail; use Theorem 4.2.4(a) only
