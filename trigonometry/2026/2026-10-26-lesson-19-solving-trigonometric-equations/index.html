Unit circle and rectangular graph

Linear Methods
Isolate the trigonometric function

We can apply the familiar techniques for solving linear equations when solving trigonometric equations. The goal is to isolate the trigonometric function using algebraic operations such as adding, subtracting, multiplying, and dividing on both sides.

Example 2. Solve each equation. Give solutions on the interval \([0, 2\pi)\) and again on the interval \((-\infty, \infty)\).

Isolate\([0, 2\pi)\)\((-\infty, \infty)\)
(a) \(3\sqrt{3}\csc(x) = 6\)\(\sin(x) = \dfrac{\sqrt{3}}{2}\)\(\left\{\dfrac{\pi}{3}, \dfrac{2\pi}{3}\right\}\)\(x = \dfrac{\pi}{3} + 2\pi k\), \(x = \dfrac{2\pi}{3} + 2\pi k\)
(b) \(3\sqrt{3}\csc(2x) = 6\)\(\sin(2x) = \dfrac{\sqrt{3}}{2}\)\(\left\{\dfrac{\pi}{6}, \dfrac{\pi}{3}, \dfrac{7\pi}{6}, \dfrac{4\pi}{3}\right\}\)\(x = \dfrac{\pi}{6} + \pi k\), \(x = \dfrac{\pi}{3} + \pi k\)
(c) \(2\tan\left(\dfrac{x}{2}\right) - 1 = \tan\left(\dfrac{x}{2}\right)\)\(\tan\left(\dfrac{x}{2}\right) = 1\)\(\left\{\dfrac{\pi}{2}\right\}\)\(x = \dfrac{\pi}{2} + 2\pi k\)
Factoring Methods
Zero-product property

There are times when basic arithmetic (addition, subtraction, multiplication, and division) is not sufficient to isolate the trigonometric function. In these cases, factoring methods and the zero-product property may be helpful. Recall the zero-product property states if \(a \cdot b = 0\), then either \(a = 0\) or \(b = 0\) (or both).

Example 3. Use factoring and the zero-product property to solve each trigonometric equation. Give solutions on the interval \([0^\circ, 360^\circ)\) and again on \((-\infty, \infty)\).

Factor\([0^\circ, 360^\circ)\)\((-\infty, \infty)\)
(a) \(\sin^2(x) = 3\sin(x)\)\(\sin(x)\left(\sin(x) - 3\right) = 0\): \(\sin(x) = 3\) has no solution\(\{0^\circ, 180^\circ\}\)\(x = 0^\circ + 180^\circ k\)
(b) \(\sin(x)\sec(x) = -\dfrac{2}{\sqrt{3}}\sin(x)\)\(\sin(x)\left(\sec(x) + \dfrac{2}{\sqrt{3}}\right) = 0\): \(\sin(x) = 0\) or \(\cos(x) = -\dfrac{\sqrt{3}}{2}\)\(\{0^\circ, 180^\circ, 150^\circ, 210^\circ\}\)\(x = 180^\circ k\), \(x = 150^\circ + 360^\circ k\), \(x = 210^\circ + 360^\circ k\)

The zeros of the left side minus the right side are the solutions.

Example 4
Factoring

Use factoring and the zero-product property to solve the trigonometric equation. Give solutions on the interval \([0, 2\pi)\).

\(2\cos^2(x) - 3\cos(x) + 1 = 0\)

  • Let \(u = \cos(x)\): \(2u^2 - 3u + 1 = (2u - 1)(u - 1) = 0\)
  • \(u = \dfrac{1}{2}\): \(\cos(x) = \dfrac{1}{2}\), \(x = \dfrac{\pi}{3}, \dfrac{5\pi}{3}\)
  • \(u = 1\): \(\cos(x) = 1\), \(x = 0\)
  • Solution set: \(\left\{0, \dfrac{\pi}{3}, \dfrac{5\pi}{3}\right\}\)
Applying Identities
Example 5

When dealing with equations that involve more than one trigonometric function, or multiple angles, it may be helpful to apply an identity and rewrite the equation in terms of a single trigonometric function or a single angle.

Example 5. Find a useful identity and solve the equation. Give solutions on the interval \((-\infty, \infty)\).

\(3\sin(2x) = -2\sin(x)\cos(x)\)

  • Identity: \(\sin(2x) = 2\sin(x)\cos(x)\), so \(3\sin(2x) = -\sin(2x)\)
  • Isolate: \(4\sin(2x) = 0\), \(\sin(2x) = 0\)
  • Solve: \(2x = \pi k\), \(x = \dfrac{\pi k}{2}\), \(k\) any integer

Give solutions on the interval \((-\infty, \infty)\).

\(-2\sin^2(x) - 3\cos(x) + 3 = 0\)

  • From Example 4: \(x = 0 + 2\pi k\), \(x = \dfrac{\pi}{3} + 2\pi k\), \(x = \dfrac{5\pi}{3} + 2\pi k\)
Calculator Approximations
Inverse functions and two useful identities

We will not always work exclusively with values found along the unit circle. In applications, calculator approximations are frequently required to obtain results. More specifically, we often need the calculator to approximate inverse trigonometric function values. Two identities are particularly helpful in these cases.

Important Info: Useful Identities for Solving Trigonometric Equations

For trigonometric equations requiring calculator approximations, the inverse functions are often needed. Due to the restrictions placed on inverse trigonometric functions, it may be convenient to apply the following identities to ensure that all solutions are found.

Even Identity for Cosine\(\cos(-\theta) = \cos(\theta)\)
Supplementary Angle Identity for Sine
(a result of the difference identity for sine)		\(\sin(\theta) = \sin(\pi - \theta)\), \(\theta\) in radians
\(\sin(\theta) = \sin(180^\circ - \theta)\), \(\theta\) in degrees

Blue is the angle the calculator returns, red is the other one.
