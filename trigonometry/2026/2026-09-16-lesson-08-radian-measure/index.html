Radian Measure
A circular perspective on angles

Up to now, every angle measure in this course has been given in degrees, a well-known unit found in applications like navigation and surveying. Mathematics and related fields more often use an alternative: radian measure.

Radian measure compares the radius of a circle to the length along the intercepted arc of a central angle (an angle with vertex at the circle's center). In a circle of radius \(1\), a central angle of \(1\) radian intercepts an arc of length \(1\); an angle of \(2\) radians intercepts an arc of length \(2\), and so on.

As a rule, any angle measure with no units stated is assumed to be in radians.

Definition: The Radian

A radian is an angle which, if placed with its vertex at the center of a circle, intercepts an arc with length equal to the radius of that circle.

Example 1
Graph each angle

(a) \(\theta = 1\)

(b) \(\theta = 3\)

Notice \(\theta = 3\) is just shy of \(\pi \approx 3.14\), a half rotation (\(180°\)).

(c) \(\theta = 6\)

And \(\theta = 6\) is just shy of \(2\pi \approx 6.28\), a full rotation (\(360°\)).

Radian-Degree Conversion
Two well-known angles

To convert between degree and radian measure, we reference two angles:

\(360\)° = \(2\pi\) radians \(\approx 6.28\) radians

\(180\)° = \(\pi\) radians \(\approx 3.14\) radians

Either equation gives a "unit ratio" equal to \(1\): \(\dfrac{180°}{\pi} = \dfrac{\pi}{180°} = 1\)

To convert degrees to radians, multiply by \(\dfrac{\pi}{180°}\) (this multiplies "in" the radian measure and divides "out" the degree measure).

To convert radians to degrees, multiply by \(\dfrac{180°}{\pi}\) (this multiplies "in" the degree measure and divides "out" the radian measure).

Example 2 (a)–(b)
Convert degrees to radians

(a) \(225°\)

\(225° \left(\dfrac{\pi}{180°}\right) = \dfrac{225}{180}\pi = \dfrac{5}{4}\pi = \dfrac{5\pi}{4}\)

(b) \(-60°\)

\(-60° \left(\dfrac{\pi}{180°}\right) = -\dfrac{60}{180}\pi = -\dfrac{1}{3}\pi = -\dfrac{\pi}{3}\)

Example 2 (c)–(d)
Convert radians to degrees

(c) \(\dfrac{3\pi}{4}\)

\(\dfrac{3\pi}{4} \left(\dfrac{180°}{\pi}\right) = \dfrac{3}{4}(180°) = 135°\)

(d) \(\dfrac{7\pi}{12}\)

\(\dfrac{7\pi}{12} \left(\dfrac{180°}{\pi}\right) = \dfrac{7}{12}(180°) = 105°\)

Procedure: Reference Angle, in Radians
For any non-quadrantal angle \(\theta\), in standard position

Step 1: If \(\theta > 2\pi\) or \(\theta < 0\), find a coterminal angle by adding or subtracting \(2\pi\) as many times as needed to get an angle between \(0\) and \(2\pi\).

Step 2: If the result from Step 1 is between \(0\) and \(\dfrac{\pi}{2}\), that result is \(\theta_r\). If not, subtract \(\pi\) and continue to Step 3.

Step 3: If the result from Step 2 is between \(0\) and \(\dfrac{\pi}{2}\), that result is \(\theta_r\). If it's between \(-\dfrac{\pi}{2}\) and \(0\), \(\theta_r\) is its absolute value. If neither, subtract \(\pi\) and repeat this step.

Identical in spirit to the degree-based procedure from Lesson 06, just rewritten with \(\pi\) and \(2\pi\) standing in for \(180°\) and \(360°\).

Example 3 (a)–(b)
Find the reference angle, if possible

(a) \(\theta = \dfrac{5\pi}{3}\)

Not in \((0, \pi/2)\), so subtract \(\pi\): \(\dfrac{5\pi}{3} - \pi = \dfrac{2\pi}{3}\). Not in \((0,\pi/2)\) either; subtract \(\pi\) again: \(\dfrac{2\pi}{3} - \pi = -\dfrac{\pi}{3}\), between \(-\pi/2\) and \(0\), so \(\theta_r = \dfrac{\pi}{3}\)

(b) \(\theta = \dfrac{7\pi}{6}\)

Not in \((0,\pi/2)\); subtract \(\pi\): \(\dfrac{7\pi}{6} - \pi = \dfrac{\pi}{6}\), between \(0\) and \(\pi/2\), so \(\theta_r = \dfrac{\pi}{6}\)

Example 3 (c)–(d)
Find the reference angle, if possible

(c) \(\theta = \dfrac{3\pi}{4}\)

Not in \((0,\pi/2)\); subtract \(\pi\): \(\dfrac{3\pi}{4} - \pi = -\dfrac{\pi}{4}\), between \(-\pi/2\) and \(0\), so \(\theta_r = \dfrac{\pi}{4}\)

(d) \(\theta = 3\pi\)

\(3\pi\) is coterminal with \(\pi\), a quadrantal angle, so \(\theta_r\) is undefined (DNE)

Example 3 (e)–(f)
Find the reference angle, if possible

(e) \(\theta = \dfrac{8\pi}{3}\)

Greater than \(2\pi\); subtract \(2\pi\): \(\dfrac{8\pi}{3} - 2\pi = \dfrac{2\pi}{3}\). Not in \((0,\pi/2)\); subtract \(\pi\): \(\dfrac{2\pi}{3} - \pi = -\dfrac{\pi}{3}\), between \(-\pi/2\) and \(0\), so \(\theta_r = \dfrac{\pi}{3}\)

(f) \(\theta = -\dfrac{19\pi}{6}\)

Negative; add \(2\pi\) twice: \(-\dfrac{19\pi}{6} + 2\pi = -\dfrac{7\pi}{6}\), still negative, \(-\dfrac{7\pi}{6} + 2\pi = \dfrac{5\pi}{6}\). Not in \((0,\pi/2)\); subtract \(\pi\): \(\dfrac{5\pi}{6} - \pi = -\dfrac{\pi}{6}\), between \(-\pi/2\) and \(0\), so \(\theta_r = \dfrac{\pi}{6}\)

Same values as the degree-based chart from Lesson 03, just with the angles relabeled in radians: \(0°, 30°, 45°, 60°, 90°\) become \(0, \pi/6, \pi/4, \pi/3, \pi/2\).

Example 5 (a)–(b)
Evaluate using reference angles

(a) \(\sin\left(\dfrac{5\pi}{3}\right)\)

\(\dfrac{5\pi}{3} \in\) QIV, where sine is negative. \(\theta_r = \dfrac{\pi}{3}\), so \(\sin\left(\dfrac{5\pi}{3}\right) = -\sin\left(\dfrac{\pi}{3}\right) = -\dfrac{\sqrt{3}}{2}\)

(b) \(\cos\left(\dfrac{7\pi}{6}\right)\)

\(\dfrac{7\pi}{6} \in\) QIII, where cosine is negative. \(\theta_r = \dfrac{\pi}{6}\), so \(\cos\left(\dfrac{7\pi}{6}\right) = -\cos\left(\dfrac{\pi}{6}\right) = -\dfrac{\sqrt{3}}{2}\)

Example 5 (c)–(d)
Evaluate using reference angles

(c) \(\tan\left(\dfrac{3\pi}{4}\right)\)

\(\dfrac{3\pi}{4} \in\) QII, where tangent is negative. \(\theta_r = \dfrac{\pi}{4}\), so \(\tan\left(\dfrac{3\pi}{4}\right) = -\tan\left(\dfrac{\pi}{4}\right) = -1\)

(d) \(\csc\left(\dfrac{8\pi}{3}\right)\)

\(\dfrac{8\pi}{3} - 2\pi = \dfrac{2\pi}{3}\) coterminal, shown above.

\(\dfrac{8\pi}{3}\) is coterminal with \(\dfrac{2\pi}{3} \in\) QII, where cosecant (reciprocal of sine) is positive. \(\theta_r = \dfrac{\pi}{3}\), so \(\csc\left(\dfrac{8\pi}{3}\right) = \csc\left(\dfrac{\pi}{3}\right) = \dfrac{1}{\sin(\pi/3)} = \dfrac{2}{\sqrt{3}} = \dfrac{2\sqrt{3}}{3}\)

Looking Ahead
Radians unlock the rest of the toolkit

With radian measure defined, angles can now be treated as plain real numbers, which is exactly what lets us define the unit circle's coordinates as \((\cos\theta, \sin\theta)\), talk about arc length as \(s = r\theta\), and eventually study the trig functions as functions of a real variable, not just an angle in a triangle.
