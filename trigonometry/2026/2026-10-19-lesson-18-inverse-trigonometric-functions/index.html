Inverse Trigonometric Functions

Review of Functions and Inverse Functions
Relations and functions

The topic of inverse trigonometric functions can be difficult. To better understand them, we first review functions and inverse functions in general.

Definition: Relations and Functions

A relation is a correspondence between an input set, called the domain, and an output set, called the range. Generally, a relation is any set of ordered pairs where the first component is an element from the domain, corresponding to the second component, an element from the range.

A function is a relation in which each element from the domain corresponds to exactly one element from the range.

Procedure: The Vertical Line Test

When viewing the graph of a relation, if all vertical lines intersect the graph in no more than one location, then the relation is a function.

One-to-One Functions
Horizontal line test and inverse functions
Definition: One-to-One Functions

A one-to-one function is a function in which each element from the range corresponds to exactly one element from the domain. It satisfies the qualities of a function in both directions.

Procedure: The Horizontal Line Test

When viewing the graph of a function, if all horizontal lines intersect the graph in no more than one location, then the function is a one-to-one function.

Definition: Inverse Functions

Assume \(f\) and \(g\) are two functions such that

1. \(f(g(x)) = x\), for every \(x\) in the domain of \(g\).

2. \(g(f(x)) = x\), for every \(x\) in the domain of \(f\).

Then \(f\) and \(g\) are mutually inverse, and we write \(g(x) = f^{-1}(x)\). Here \(-1\) is not an exponent. Only one-to-one functions have an inverse function.

Inverse Trigonometric Functions
Notation and restriction

We now relax the acute-angle restriction and consider the full domain and range for these functions.

\(\sin(\theta) = y \leftrightarrow \theta = \sin^{-1}(y)\)     \(\cos(\theta) = y \leftrightarrow \theta = \cos^{-1}(y)\)     \(\tan(\theta) = y \leftrightarrow \theta = \tan^{-1}(y)\)

These functions are not one-to-one! So how do we have inverse trigonometric functions? We restrict the domain to an interval where the function satisfies the requirements for a one-to-one function.

Definition: The Inverse Sine Function

Let \(\theta\) be any value such that \(-\dfrac{\pi}{2} \le \theta \le \dfrac{\pi}{2}\), then \(\theta = \sin^{-1}(y)\) or \(\theta = \arcsin(y)\) if and only if \(y = \sin(\theta)\).

The notations \(\sin^{-1}(y)\) and \(\arcsin(y)\) are interchangeable. The term arcsine reminds us that we are referring to the inverse of the restricted sine function.

DomainRange
Restricted sine\(\left[-\dfrac{\pi}{2}, \dfrac{\pi}{2}\right]\)\([-1, 1]\)
Arcsine\([-1, 1]\)\(\left[-\dfrac{\pi}{2}, \dfrac{\pi}{2}\right]\)

The Inverse Cosine and Tangent Functions
Restricted cosine and tangent
Definition: The Inverse Cosine Function

Let \(\theta\) be any value such that \(0 \le \theta \le \pi\), then \(\theta = \cos^{-1}(y)\) or \(\theta = \arccos(y)\) if and only if \(y = \cos(\theta)\).

Again \(\cos^{-1}(y)\) and \(\arccos(y)\) are interchangeable. The term arccosine reminds us that we are referring to the inverse of the restricted cosine function.

DomainRange
Restricted cosine\([0, \pi]\)\([-1, 1]\)
Arccosine\([-1, 1]\)\([0, \pi]\)
Definition: The Inverse Tangent Function

Let \(\theta\) be any value such that \(-\dfrac{\pi}{2} < \theta < \dfrac{\pi}{2}\), then \(\theta = \tan^{-1}(y)\) or \(\theta = \arctan(y)\) if and only if \(y = \tan(\theta)\).

Once more \(\tan^{-1}(y)\) and \(\arctan(y)\) are interchangeable. The term arctangent reminds us that we are referring to the inverse of the restricted tangent function.

DomainRange
Restricted tangent\(\left(-\dfrac{\pi}{2}, \dfrac{\pi}{2}\right)\)\((-\infty, \infty)\)
Arctangent\((-\infty, \infty)\)\(\left(-\dfrac{\pi}{2}, \dfrac{\pi}{2}\right)\)

The horizontal lines \(y = \pm\pi/2\) are asymptotes of arctangent; the vertical lines \(x = \pm\pi/2\) are asymptotes of restricted tangent.

Inverse Functions and Composition
f(f⁻¹(x)) and f⁻¹(f(x))

The definition of inverse functions is rooted in composition:

1. \(f(f^{-1}(x)) = x\), for every \(x\) in the domain of \(f^{-1}\).

2. \(f^{-1}(f(x)) = x\), for every \(x\) in the domain of \(f\).

For trigonometric functions we always satisfy \(f(f^{-1}(x)) = x\), provided \(x\) is in the domain of \(f^{-1}\). Because of the domain restrictions, we will not always satisfy \(f^{-1}(f(x)) = x\).

Approximating Inverse Function Values with a Calculator
Reciprocal identities and the cotangent mismatch

When evaluating trigonometric functions, an exact value is generally preferred over an approximation. But in real-world situations we must often use a calculator.

Most scientific calculators handle arcsine, arccosine, and arctangent, but few can evaluate arcsecant, arccosecant, and arccotangent. Use the reciprocal identities to transform the expression into one the calculator understands:

\(\sec^{-1}(x) = \) \(\cos^{-1}\left(\dfrac{1}{x}\right)\)     \(\csc^{-1}(x) = \) \(\sin^{-1}\left(\dfrac{1}{x}\right)\)

Be careful with arccotangent: its range is \((0,\pi)\), but arctangent's range is \(\left(-\dfrac{\pi}{2},\dfrac{\pi}{2}\right)\), a "mismatch".

\(\cot^{-1}(x) = \tan^{-1}\left(\dfrac{1}{x}\right)\) if \(x > 0\), and \(\cot^{-1}(x) = \tan^{-1}\left(\dfrac{1}{x}\right) + \pi\) if \(x < 0\).

Reference Triangles: Example 8
Evaluate cos(sin⁻¹(4/5))

Consider a combination of the form \(f(f^{-1}(x))\), such as \(\sin(\cos^{-1}(1))\). We find \(\theta = \cos^{-1}(1) = 0\), then evaluate \(\sin(0) = 0\).

This works well when \(\theta\) is easily found. For \(\cos\left(\sin^{-1}\left(\dfrac{4}{5}\right)\right)\), the angle \(\theta = \sin^{-1}\left(\dfrac{4}{5}\right) \approx 0.927295\ldots\) is not on the unit circle, and we only get \(\cos(0.927295\ldots) \approx 0.600236\ldots\).

Since \(\theta\) is just an intermediate step, a reference triangle gives an exact value without calculating \(\theta\).

Evaluate \(\cos\left(\sin^{-1}\left(\dfrac{4}{5}\right)\right)\) by completing the following steps.

(a) Let \(\sin^{-1}\left(\dfrac{4}{5}\right) = \theta\). Write this statement in its inverse form. \(\sin\theta = \dfrac{4}{5}\)

(b) Construct a right triangle with measures that satisfy part (a): opposite \(4\), hypotenuse \(5\).

3

(c) Find the missing side. \(\sqrt{5^2 - 4^2} = 3\)

(d) Evaluate \(\cos\left(\sin^{-1}\left(\dfrac{4}{5}\right)\right) = \cos\theta = \) \(\dfrac{3}{5}\)
