Introduction to Trigonometric Identities

What is an Identity
Definition

In mathematics, an identity is any equation that holds true for all values of the variable, provided those values are from the domain.

Examples:

\(\dfrac{2x}{4} = \dfrac{x}{2}\),    \(2(x+4) = -6x + 4(2+2x)\),    \(\log(2x) = \log(2) + \log(x)\)

On occasion an identity is something apparent, but the more useful ones often express relationships that are not obvious — it can take real effort to verify an equation is an identity, which we'll address later. For now we focus on applying some of the more fundamental identities.

Definitions: Ratio and Reciprocal Identities
Let \(\theta\) be any value for which the functions below are defined
Reciprocal\(\sin(\theta) = \dfrac{1}{\csc(\theta)}\)\(\csc(\theta) = \dfrac{1}{\sin(\theta)}\)
\(\cos(\theta) = \dfrac{1}{\sec(\theta)}\)\(\sec(\theta) = \dfrac{1}{\cos(\theta)}\)
\(\tan(\theta) = \dfrac{1}{\cot(\theta)}\)\(\cot(\theta) = \dfrac{1}{\tan(\theta)}\)
Ratio\(\tan(\theta) = \dfrac{\sin(\theta)}{\cos(\theta)}\)\(\cot(\theta) = \dfrac{\cos(\theta)}{\sin(\theta)}\)

Tips: tangent and cotangent are "cofunctions" (similar names), but don't confuse this with the cofunction identities later in this lesson — entirely separate from reciprocal identities. A reciprocal pair always has differing first letters: cosecant can't pair with cosine (same letter), so cosecant pairs with sine, and cosine pairs with secant.

Example 1
Finding the remaining four ratios

Given \(\sin(\theta) = \dfrac{2\sqrt{6}}{7}\) and \(\tan(\theta) = \dfrac{2\sqrt{6}}{5}\), find the remaining four trig ratios.

\(\csc(\theta) = \dfrac{1}{\sin(\theta)} = \) \(\dfrac{7\sqrt{6}}{12}\)     \(\cot(\theta) = \dfrac{1}{\tan(\theta)} = \) \(\dfrac{5\sqrt{6}}{12}\)

\(\cos(\theta) = \dfrac{\sin(\theta)}{\tan(\theta)} = \) \(\dfrac{5}{7}\)     \(\sec(\theta) = \dfrac{1}{\cos(\theta)} = \) \(\dfrac{7}{5}\)

Example 2
Where is each ratio undefined?

For \(0° \le \theta < 360°\), \(\sin(0°) = \sin(180°) = \cos(90°) = \cos(270°) = 0\). Using this and the ratio/reciprocal identities, determine where each is undefined.

(a) \(\tan(\theta) = \dfrac{\sin\theta}{\cos\theta}\) — undefined when \(\cos\theta = 0\):

\(\theta = 90°\) and \(\theta = 270°\)

(b) \(\cot(\theta) = \dfrac{\cos\theta}{\sin\theta}\) — undefined when \(\sin\theta = 0\):

\(\theta = 0°\) and \(\theta = 180°\)

(c) \(\sec(\theta) = \dfrac{1}{\cos\theta}\) — undefined when \(\cos\theta = 0\):

\(\theta = 90°\) and \(\theta = 270°\)

(d) \(\csc(\theta) = \dfrac{1}{\sin\theta}\) — undefined when \(\sin\theta = 0\):

\(\theta = 0°\) and \(\theta = 180°\)

Example 3 (a)–(c)
The unit circle — sine and cosine as coordinates

Drag the point around the circle below (radius \(1\) — the unit circle). Pick any point \(P(x,y)\) and imagine the angle \(\theta\), in standard position, whose terminal side passes through \(P\).

Since the radius is \(r = 1\): \(\sin(\theta) = \dfrac{y}{r} = \) \(y\)     \(\cos(\theta) = \dfrac{x}{r} = \) \(x\)

On the unit circle, the point's coordinates are \((\cos\theta, \sin\theta)\).

Example 3 (d)–(f)
The Pythagorean identity, domain &amp; range

Drop a right triangle from \(P\) to the \(x\)-axis: hypotenuse \(1\) (the radius), legs \(|x|\) and \(|y|\).

(d) By the Pythagorean theorem: \(|x|^2 + |y|^2 = 1^2 \ \Rightarrow\ \) \(x^2 + y^2 = 1\)

(e) Substituting \(x = \cos\theta\), \(y = \sin\theta\) from the previous step:

\(\cos^2(\theta) + \sin^2(\theta) = 1\) — the Pythagorean identity!

(f) \(\theta\) represents any amount of rotation, so its domain is \((-\infty, \infty)\). Since \(-1 \le y \le 1\) and \(-1 \le x \le 1\) on the unit circle:

\(\sin(\theta) \in \) \([-1, 1]\)     \(\cos(\theta) \in \) \([-1, 1]\)

Definitions: Pythagorean Identities
Divide the identity above by \(\cos^2\theta\) or \(\sin^2\theta\) to get the other two
\(\sin^2(\theta) + \cos^2(\theta) = 1\)
\(\tan^2(\theta) + 1 = \sec^2(\theta)\)
\(\cot^2(\theta) + 1 = \csc^2(\theta)\)

Dividing \(\sin^2\theta + \cos^2\theta = 1\) through by \(\cos^2\theta\) gives \(\tan^2\theta + 1 = \sec^2\theta\); dividing instead by \(\sin^2\theta\) gives \(1 + \cot^2\theta = \csc^2\theta\). You only need to remember the first form — the other two follow from it.

Example 4
Using a Pythagorean identity with quadrant sign

Let \(\theta\) be an angle in quadrant III such that \(\cos(\theta) = -\dfrac{3}{4}\). Find \(\sin(\theta)\) and \(\cot(\theta)\).

\(\sin^2\theta = 1 - \cos^2\theta = 1 - \dfrac{9}{16} = \dfrac{7}{16}\ \Rightarrow\ \sin\theta = \pm\sqrt{\dfrac{7}{16}}\). Since \(\theta \in\) QIII, \(\sin\theta < 0\):

\(\sin(\theta) = \) \(-\dfrac{\sqrt{7}}{4}\)

\(\cot(\theta) = \dfrac{\cos\theta}{\sin\theta} = \) \(\dfrac{3\sqrt{7}}{7}\)

Example 5
A common mistake

On her exam, Ariel was given \(\tan(\theta) = \dfrac{3}{2}\) and asked to find \(\sin(\theta)\) and \(\cos(\theta)\). She claimed \(\sin(\theta) = 3\) and \(\cos(\theta) = 2\). She got partial credit, but not full marks. Why?

\(\tan\theta = \sin\theta/\cos\theta\) does not mean the numerator and denominator of a ratio in lowest terms are the actual sine and cosine values — both \(\sin\theta\) and \(\cos\theta\) must lie in \([-1,1]\), so \(\sin\theta = 3\) is impossible. She recognized the ratio form, but not that constraint.

Correct solution, using \(\tan^2\theta + 1 = \sec^2\theta\):

\(\sec\theta = \pm\sqrt{\tan^2\theta+1} = \pm\sqrt{\left(\frac{3}{2}\right)^2+1} = \) \(\pm\dfrac{\sqrt{13}}{2}\)

\(\cos(\theta) = \dfrac{1}{\sec\theta} = \) \(\pm\dfrac{2\sqrt{13}}{13}\)     \(\sin(\theta) = \cos\theta\tan\theta = \) \(\pm\dfrac{3\sqrt{13}}{13}\)

No quadrant was given, so both signs are valid (tangent is positive in QI and QIII).

Example 6 (a)–(e)
The cofunction identities — deriving from a right triangle

Sine & cosine, secant & cosecant, tangent & cotangent — let's develop the relationship between each pair.

(a) The missing angle, labeled above, is \(90° - \theta\) (the two acute angles are complementary).

(b) \(\sin(\theta) = \dfrac{b}{c}\). Viewed from the other acute angle, \(b\) is the adjacent side to \(90°-\theta\), so this is also \(\cos(90°-\theta)\): \(\sin(\theta) = \) \(\cos(90° - \theta)\)

(c) \(\sec(\theta) = \dfrac{c}{a}\), and from \(90°-\theta\)'s perspective this is \(\csc(90°-\theta)\): \(\sec(\theta) = \) \(\csc(90° - \theta)\)

(d) \(\tan(\theta) = \dfrac{b}{a}\), which is \(\cot(90°-\theta)\): \(\tan(\theta) = \) \(\cot(90° - \theta)\)

Definitions: Cofunction Identities
For any acute angle \(\theta\)
\(\sin(\theta) = \cos(90° - \theta)\)\(\cos(\theta) = \sin(90° - \theta)\)
\(\sec(\theta) = \csc(90° - \theta)\)\(\csc(\theta) = \sec(90° - \theta)\)
\(\tan(\theta) = \cot(90° - \theta)\)\(\cot(\theta) = \tan(90° - \theta)\)

Note: \(\theta\) and \(90° - \theta\) are always complementary — they sum to \(90°\).
