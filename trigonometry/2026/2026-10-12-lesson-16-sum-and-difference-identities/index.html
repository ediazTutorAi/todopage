Sum and Difference Identities

Motivating Example
Evaluating with the unit circle

Example 1. Evaluate each expression using the unit circle.

(a) \(\sin\left(\dfrac{17\pi}{6}\right)\)\(\sin\left(\dfrac{5\pi}{6}\right) = \dfrac{1}{2}\)\(\dfrac{17\pi}{6} - \dfrac{12\pi}{6} = \dfrac{5\pi}{6}\)
(b) \(\cos(1050^\circ)\)\(\cos(330^\circ) = \dfrac{\sqrt{3}}{2}\)\(1050 - 720 = 330\)
(c) \(\tan\left(-\dfrac{11\pi}{6}\right)\)\(\tan\left(\dfrac{\pi}{6}\right) = \dfrac{1/2}{\sqrt{3}/2} = \dfrac{\sqrt{3}}{3}\)\(-\dfrac{11\pi}{6} + \dfrac{12\pi}{6} = \dfrac{\pi}{6}\)
(d) \(\sin(15^\circ)\)The unit circle has no point at \(15^\circ\), so we cannot get an exact value yet. We can only say \(0 < \sin(15^\circ) < \dfrac{1}{2}\).

The first three land on a special angle. For (d), can we rewrite \(15^\circ\) using angles that are on the unit circle?

The Big Question
Is sine of a sum the sum of the sines?

\(15^\circ = 45^\circ - 30^\circ\), and both pieces are on the unit circle. A tempting idea is to "distribute":

\(\sin(45^\circ - 30^\circ) \stackrel{?}{=} \sin(45^\circ) - \sin(30^\circ) = \dfrac{\sqrt{2}}{2} - \dfrac{1}{2} \approx\) \(0.207\)

But \(\sin(15^\circ) \approx\) \(0.259\). So sine does not distribute over a difference.

Here is the same failure as a graph: \(y = \sin(x + 30^\circ)\) against the "distributed" \(y = \sin x + \sin 30^\circ\).

The curves are never the same shape: one is a shifted sine, the other a raised sine. We need a correct rule.

The Sum and Difference Identities
Property

For any angles \(A\) and \(B\) where the functions are defined:

SumDifference
Sine\(\sin(A+B) = \) \(\sin A\cos B + \cos A\sin B\)\(\sin(A-B) = \) \(\sin A\cos B - \cos A\sin B\)
Cosine\(\cos(A+B) = \) \(\cos A\cos B - \sin A\sin B\)\(\cos(A-B) = \) \(\cos A\cos B + \sin A\sin B\)
Tangent\(\tan(A+B) = \) \(\dfrac{\tan A + \tan B}{1 - \tan A\tan B}\)\(\tan(A-B) = \) \(\dfrac{\tan A - \tan B}{1 + \tan A\tan B}\)

Watch the signs: sine keeps the sign of the angle operation, cosine flips it, and tangent has the same sign on top and the opposite sign on the bottom.

Example 2
Deriving the difference identities

Use the sum identities together with the even/odd identities (\(\cos(-B) = \cos B\), \(\sin(-B) = -\sin B\), \(\tan(-B) = -\tan B\)) to verify the difference identities. Write \(A - B = A + (-B)\).

StepReason
\(\sin(A - B) = \sin(A + (-B))\)Rewrite as a sum
\(= \sin A\cos(-B) + \cos A\sin(-B)\)Sum identity
\(= \sin A\cos B - \cos A\sin B\)Even/odd: \(\cos(-B) = \cos B\), \(\sin(-B) = -\sin B\)
\(\cos(A - B) = \cos(A + (-B))\)Rewrite as a sum
\(= \cos A\cos(-B) - \sin A\sin(-B) = \cos A\cos B + \sin A\sin B\)Sum identity, then even/odd (the two minus signs make a plus)
\(\tan(A - B) = \tan(A + (-B))\)Rewrite as a sum
\(= \dfrac{\tan A + \tan(-B)}{1 - \tan A\tan(-B)} = \dfrac{\tan A - \tan B}{1 + \tan A\tan B}\)Sum identity, then \(\tan(-B) = -\tan B\)

Example 4
Finding the missing values first

Suppose \(A\) and \(B\) are in quadrant II with \(\sin A = \dfrac{4}{5}\) and \(\cos B = -\dfrac{5}{13}\). Evaluate \(\sin(A - B)\).

The identity needs \(\sin A\), \(\cos B\), \(\cos A\), \(\sin B\). Two are missing.

StepReason
\(\sin(A - B) = \sin A\cos B - \cos A\sin B\)Difference identity
\(\cos A = -\sqrt{1 - \left(\dfrac{4}{5}\right)^2} = -\dfrac{3}{5}\)Pythagorean identity; cosine is negative in QII
\(\sin B = +\sqrt{1 - \left(-\dfrac{5}{13}\right)^2} = \dfrac{12}{13}\)Pythagorean identity; sine is positive in QII
\(\dfrac{4}{5}\left(-\dfrac{5}{13}\right) - \left(-\dfrac{3}{5}\right)\left(\dfrac{12}{13}\right) = -\dfrac{20}{65} + \dfrac{36}{65} = \dfrac{16}{65}\)Substitute and simplify

Check in the explorer: \(A = 180 - 53.13 = 126.87^\circ\), \(B = 180 - 67.38 = 112.62^\circ\), difference, sine gives \(0.246\approx 16/65\).

Example 5
Confirming the cofunction identities

If possible, use the sum/difference identities to confirm each cofunction identity.

\(\cos(90^\circ - \theta) = \sin\theta\)\(\tan\left(\dfrac{\pi}{2} - \theta\right) = \cot\theta\)
\(\cos 90^\circ\cos\theta + \sin 90^\circ\sin\theta\)\(\dfrac{\tan(\pi/2) - \tan\theta}{1 + \tan(\pi/2)\tan\theta}\)
\(= 0\cdot\cos\theta + 1\cdot\sin\theta = \sin\theta\) ✓\(\tan(\pi/2)\) is undefined, so the tangent identity cannot be applied here.

For the tangent, rewrite first: \(\tan\left(\dfrac{\pi}{2} - \theta\right) = \dfrac{\sin(\pi/2 - \theta)}{\cos(\pi/2 - \theta)} = \dfrac{\cos\theta}{\sin\theta} = \cot\theta\)

The graphs agree, so the identity is true. The sum/difference tangent rule just is not the tool for it.

Example 6
Double-angle identities, a preview

Use the sum identities with \(2\theta = \theta + \theta\) to confirm these. They come back in the next lesson.

\(\sin(2\theta) = 2\sin\theta\cos\theta\)\(\cos(2\theta) = \cos^2\theta - \sin^2\theta\)
\(\sin(\theta + \theta) = \sin\theta\cos\theta + \cos\theta\sin\theta\)\(\cos(\theta + \theta) = \cos\theta\cos\theta - \sin\theta\sin\theta\)
\(= 2\sin\theta\cos\theta\) ✓\(= \cos^2\theta - \sin^2\theta\) ✓

Careful: \(\cos^2\theta - \sin^2\theta\) has a minus. It is not the Pythagorean identity \(\cos^2\theta + \sin^2\theta = 1\).

Example 7
Simplifying an expression

Simplify \(\dfrac{\sec(x + \pi)}{\csc\left(\dfrac{\pi}{2} - x\right)}\).

StepReason
\(\dfrac{\sec(x + \pi)}{\csc(\pi/2 - x)}\)Starting expression
\(\dfrac{\sin(\pi/2 - x)}{\cos(x + \pi)}\)Reciprocal identities (\(\sec = 1/\cos\), \(\csc = 1/\sin\)), then flip the complex fraction
\(\dfrac{\sin\frac{\pi}{2}\cos x - \cos\frac{\pi}{2}\sin x}{\cos x\cos\pi - \sin x\sin\pi}\)Difference identity on top, sum identity on bottom
\(\dfrac{1\cdot\cos x - 0\cdot\sin x}{\cos x\cdot(-1) - \sin x\cdot 0} = \dfrac{\cos x}{-\cos x}\)Unit circle values
\(-1\)Cancel \(\cos x\)

Holes appear where \(\cos x = 0\), where the original expression is undefined.

Proof of sin(A + B)
Building it from right triangles

\(A, B\) acute, \(OR = 1\). Drop \(R\) to \(Q\) on the first ray, then \(Q\) to the axis.

\(\cos B\)\(\sin B\)\(1\)\(\sin A\cos B\)\(\cos A\sin B\)\(\sin(A+B)\)\(A\)\(B\)\(A\)\(Q\)\(R\)\(O\)\(S\)\(T\)

Click each blank to reveal a side. Red ruler = height of \(R\) = \(\sin(A+B)\); the green plus purple stack reaches the same height.

Proof of sin(A + B)
Reading the sides off the triangles
TriangleSideReason
\(\triangle OQR\) (right angle at \(Q\), angle \(B\) at \(O\), hypotenuse \(1\))\(OQ = \cos B\), \(QR = \sin B\)Adjacent and opposite to \(B\) with hypotenuse \(1\)
\(\triangle OSQ\) (angle \(A\) at \(O\), hypotenuse \(OQ = \cos B\))\(QS = \cos B\cdot\sin A\)Opposite \(A\) = hypotenuse \(\times\sin A\)
Angle at \(Q\) in \(\triangle QTR\)\(A\)\(QR\perp OQ\) and \(QT\perp OS\), so the angle between \(QR\) and \(QT\) equals the angle between \(OQ\) and \(OS\)
\(\triangle QTR\) (angle \(A\) at \(Q\), hypotenuse \(QR = \sin B\))\(QT = \sin B\cdot\cos A\)Adjacent \(A\) = hypotenuse \(\times\cos A\)
Height of \(R\) above the axis\(\sin(A+B) = QS + QT\)\(R\) is at height \(QS\) (to reach \(Q\)) plus \(QT\) (up to \(R\)'s level), and \(OR = 1\)

Conclusion: \(\sin(A+B) = \sin A\cos B + \cos A\sin B\)

The difference identity follows from this by replacing \(B\) with \(-B\) (Example 2), and the cosine identities have a similar picture.
