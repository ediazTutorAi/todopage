Review of Fundamental Identities
What is an identity?

An identity is an equation that is true for all values of the variable, as long as those values are in the domain.

Compare the two sides of each equation as graphs. Which one is an identity?

\(\sin^2 x + \cos^2 x = 1\)Identity: the two graphs are the same line for every \(x\).
\(\sin x = \cos x\)Not an identity: the graphs only meet at some \(x\) (those are the solutions).

Pythagorean Identities
Where \(\sin^2\theta + \cos^2\theta = 1\) comes from

Drag the point around the unit circle. Here \(x = \cos\theta\) and \(y = \sin\theta\).

Square each coordinate and add. What do you get, wherever the point sits?

\(\sin^2\theta + \cos^2\theta = 1\) (the circle \(x^2 + y^2 = 1\))

Two More Pythagorean Identities
Divide the first one

Start from \(\sin^2\theta + \cos^2\theta = 1\).

Divide every term by \(\sin^2\theta\)\(1 + \cot^2\theta = \csc^2\theta\)
Divide every term by \(\cos^2\theta\)\(\tan^2\theta + 1 = \sec^2\theta\)

Each one also rearranges, for example \(\cos^2\theta = 1 - \sin^2\theta\).

Example 1
Using a Pythagorean identity

Let \(\theta\) be an angle such that \(\cos\theta > 0\) and \(\sin\theta = -\dfrac{2}{3}\). Find \(\cos\theta\) and \(\tan\theta\).

\(\cos^2\theta = 1 - \sin^2\theta = 1 - \dfrac{4}{9} = \dfrac{5}{9}\), so \(\cos\theta = \pm\dfrac{\sqrt5}{3}\). Since \(\cos\theta > 0\), \(\cos\theta = \dfrac{\sqrt5}{3}\).

\(\tan\theta = \dfrac{\sin\theta}{\cos\theta} = \dfrac{-2/3}{\sqrt5/3} = -\dfrac{2}{\sqrt5} = -\dfrac{2\sqrt5}{5}\)
Even and Odd Functions
Symmetry of the graph

A function \(f\) is even if \(f(-x) = f(x)\) for every \(x\) in its domain. Its graph is symmetric about the \(y\)-axis.

A function \(f\) is odd if \(f(-x) = -f(x)\) for every \(x\) in its domain. Its graph is symmetric about the origin.

Even and Odd Identities
Which trig functions are even, which are odd?

Let \(\theta\) be any value for which the functions are defined. Fill in each result and say whether it is even or odd.

\(\sin(-\theta)\)\(-\sin\theta\) (odd)\(\csc(-\theta)\)\(-\csc\theta\) (odd)
\(\cos(-\theta)\)\(\cos\theta\) (even)\(\sec(-\theta)\)\(\sec\theta\) (even)
\(\tan(-\theta)\)\(-\tan\theta\) (odd)\(\cot(-\theta)\)\(-\cot\theta\) (odd)

Only cosine and its reciprocal secant are even.

Example 2
Verify the remaining even/odd identities

Using the even/odd identities for sine and cosine, along with other fundamental identities, verify the other four.

\(\sec(-\theta) = \dfrac{1}{\cos(-\theta)} = \dfrac{1}{\cos\theta} = \sec\theta\)

\(\csc(-\theta) = \dfrac{1}{\sin(-\theta)} = \dfrac{1}{-\sin\theta} = -\csc\theta\)

\(\tan(-\theta) = \dfrac{\sin(-\theta)}{\cos(-\theta)} = \dfrac{-\sin\theta}{\cos\theta} = -\tan\theta\)

\(\cot(-\theta) = \dfrac{\cos(-\theta)}{\sin(-\theta)} = \dfrac{\cos\theta}{-\sin\theta} = -\cot\theta\)

\(\csc(-\theta)\)\(-\csc\theta = \dfrac{-1}{-2/3} = \dfrac{3}{2}\)

Useful Applications
Rewrite in terms of a single function

An equation with a single trig function is easier to work with than one with several. Identities let us convert.

Example 4. Write \(-2\sin^2 x + \cos x + 1\) in terms of a single trig function and factor.

Replace \(\sin^2 x\) with \(1 - \cos^2 x\):

\(-2(1 - \cos^2 x) + \cos x + 1 = 2\cos^2 x + \cos x - 1\)

Let \(u = \cos x\): \(2u^2 + u - 1 = (2u - 1)(u + 1)\), so the expression is \((2\cos x - 1)(\cos x + 1)\).
Example 5
Simplify, then solve

It is known that \(\theta \in QI\) and \(\dfrac{\sin\theta\,\cot\theta}{\csc^2\theta\,(1 - \cos^2\theta)} = \dfrac{\sqrt2}{2}\). Find \(\theta\).

Numerator: \(\sin\theta\cdot\dfrac{\cos\theta}{\sin\theta} = \cos\theta\). Denominator: \(1 - \cos^2\theta = \sin^2\theta\), so \(\csc^2\theta\sin^2\theta = 1\).

The equation becomes \(\cos\theta = \dfrac{\sqrt2}{2}\). In QI, \(\theta = \dfrac{\pi}{4}\).
