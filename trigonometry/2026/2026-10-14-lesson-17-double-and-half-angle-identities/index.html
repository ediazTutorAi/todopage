Double- and Half-Angle Identities

Motivating Idea
What happens when A = B?

Last lesson we proved the sum identities. Set \(B = A\) and the sum becomes a double angle:

\(\sin(A + A) = \sin(2A)\)     \(\cos(A + A) = \cos(2A)\)     \(\tan(A + A) = \tan(2A)\)

Quick test: is \(\sin(2\theta)\) just \(2\sin\theta\)? Try \(\theta = 30^\circ\): \(\sin(60^\circ) = \) \(\dfrac{\sqrt{3}}{2}\approx 0.866\), but \(2\sin(30^\circ) = \) \(1\). So doubling the angle does not double the sine.

What is the rule? Apply the sum identity with \(A = B = \theta\).

The Double-Angle Identities
Property

For any \(\theta\) where the functions are defined:

\(\sin(2\theta) = \) \(2\sin\theta\cos\theta\)
\(\cos(2\theta) = \) \(\cos^2\theta - \sin^2\theta\)
\(\tan(2\theta) = \) \(\dfrac{2\tan\theta}{1 - \tan^2\theta}\)

Where they come from: \(\sin(\theta+\theta) = \sin\theta\cos\theta + \cos\theta\sin\theta\), and likewise for cosine and tangent. Notice the cosine one has a minus, so it is not the Pythagorean identity.

The two graphs lie on top of each other, which is what an identity looks like.

Example 1
Variations of the double-angle identity for cosine

Use the double-angle identity and other fundamental identities to verify

\(\cos(2\theta) = 1 - 2\sin^2\theta\)     and     \(\cos(2\theta) = 2\cos^2\theta - 1\).

StepReason
\(\cos(2\theta) = \cos^2\theta - \sin^2\theta\)Double-angle identity
\(= (1 - \sin^2\theta) - \sin^2\theta\)Pythagorean: \(\cos^2\theta = 1 - \sin^2\theta\)
\(= 1 - 2\sin^2\theta\) ✓Combine like terms
\(\cos(2\theta) = \cos^2\theta - \sin^2\theta\)Double-angle identity again
\(= \cos^2\theta - (1 - \cos^2\theta)\)Pythagorean: \(\sin^2\theta = 1 - \cos^2\theta\)
\(= 2\cos^2\theta - 1\) ✓Combine like terms

So cosine has three double-angle forms. Pick the one that uses the value you already know.

Example 2
Multiples of an angle: double

Let \(\cos\theta = -\dfrac{4}{5}\) with \(\theta\) in quadrant III.

(a) Find \(\sin(2\theta)\), \(\cos(2\theta)\), and \(\tan(2\theta)\).

StepReason
\(\sin\theta = \)\(-\sqrt{1 - \left(-\dfrac{4}{5}\right)^2} = -\dfrac{3}{5}\)Pythagorean identity; sine is negative in QIII
\(\sin(2\theta) = \)\(2\left(-\dfrac{3}{5}\right)\left(-\dfrac{4}{5}\right) = \dfrac{24}{25}\)\(2\sin\theta\cos\theta\)
\(\cos(2\theta) = \)\(\left(-\dfrac{4}{5}\right)^2 - \left(-\dfrac{3}{5}\right)^2 = \dfrac{16}{25} - \dfrac{9}{25} = \dfrac{7}{25}\)\(\cos^2\theta - \sin^2\theta\)
\(\tan(2\theta) = \)\(\dfrac{24/25}{7/25} = \dfrac{24}{7}\)Ratio identity (or the tangent double-angle formula)

Multiples of an angle: 3θ and 4θ

(b) Find \(\sin(4\theta)\) and \(\sin(-4\theta)\).

StepReason

\(= 2\left(\dfrac{24}{25}\right)\left(\dfrac{7}{25}\right) = \dfrac{336}{625}\)Values from part (a)

(c) Find \(\cos(3\theta)\) and \(\cos(-3\theta)\).

StepReason

Any integer multiple of \(\theta\) can be built this way: split into pieces and combine the identities.

Power-Reducing Identities
Derive them for yourself

In calculus, integrating powers of sine and cosine depends on these. They come straight from the cosine variations in Example 1.

StartSolve for the square
\(\cos(2\theta) = 2\cos^2\theta - 1\)\(2\cos^2\theta = 1 + \cos(2\theta)\ \Rightarrow\ \cos^2\theta = \dfrac{1}{2}\bigl(1 + \cos(2\theta)\bigr)\)
\(\cos(2\theta) = 1 - 2\sin^2\theta\)\(2\sin^2\theta = 1 - \cos(2\theta)\ \Rightarrow\ \sin^2\theta = \dfrac{1}{2}\bigl(1 - \cos(2\theta)\bigr)\)

Squaring turns a curve that swings between \(-1\) and \(1\) into one that lives between \(0\) and \(1\), centered at \(\tfrac12\) with period \(\pi\).

The Half-Angle Identities
Property

Each half-angle identity comes from a double-angle identity. The \(\pm\) sign is decided by the quadrant of \(\theta/2\).

\(\sin\left(\dfrac{\theta}{2}\right) = \) \(\pm\sqrt{\dfrac{1 - \cos\theta}{2}}\)
\(\cos\left(\dfrac{\theta}{2}\right) = \) \(\pm\sqrt{\dfrac{1 + \cos\theta}{2}}\)
\(\tan\left(\dfrac{\theta}{2}\right) = \) \(\pm\sqrt{\dfrac{1 - \cos\theta}{1 + \cos\theta}}\)

A word of caution. Never leave the \(\pm\) in a final answer. A trig function at a given angle has exactly one value, so you must choose a sign.

The square root alone is never negative. It matches \(\sin(x/2)\) only while \(x/2\) is in QI or QII, and the \(\pm\) records that the true sine can be negative when \(x/2\) is in QIII or QIV.

Example 3
Deriving the half-angle identity for sine

Start with \(\cos(2x) = 1 - 2\sin^2 x\) and derive \(\sin\left(\dfrac{\theta}{2}\right)\).

StepReason
\(\cos(2x) = 1 - 2\sin^2 x\)Given
\(2\sin^2 x = 1 - \cos(2x)\)Move \(\sin^2 x\) term and \(\cos(2x)\) across
\(\sin^2 x = \dfrac{1 - \cos(2x)}{2}\)Divide by 2
\(\sin x = \pm\sqrt{\dfrac{1 - \cos(2x)}{2}}\)Square root of both sides, keeping both signs
\(\sin\left(\dfrac{\theta}{2}\right) = \pm\sqrt{\dfrac{1 - \cos\theta}{2}}\) ✓Let \(x = \theta/2\), so \(2x = \theta\)

The cosine version is the same story starting from \(\cos(2x) = 2\cos^2 x - 1\).

Tangent Half-Angle Variations
Example 5

The tangent half-angle formula has two sign-free forms that are often easier to use:

\(\tan\left(\dfrac{\theta}{2}\right) = \dfrac{\sin\theta}{1 + \cos\theta}\)     and     \(\tan\left(\dfrac{\theta}{2}\right) = \dfrac{1 - \cos\theta}{\sin\theta}\)

No \(\pm\) needed: the sign of \(\sin\theta\) already carries the right sign.

Example 5. Evaluate \(\tan\left(\dfrac{\pi}{8}\right)\).

StepReason
\(\tan\left(\dfrac{\pi}{8}\right) = \tan\left(\dfrac{\pi/4}{2}\right)\)\(\dfrac{\pi}{8}\) is half of \(\dfrac{\pi}{4}\), a unit-circle angle
\(= \dfrac{\sin(\pi/4)}{1 + \cos(\pi/4)} = \dfrac{\sqrt{2}/2}{1 + \sqrt{2}/2}\)Sign-free half-angle form
\(= \dfrac{\sqrt{2}}{2 + \sqrt{2}}\cdot\dfrac{2 - \sqrt{2}}{2 - \sqrt{2}} = \dfrac{2\sqrt{2} - 2}{2}\)Multiply top and bottom by 2, then rationalize with the conjugate
\(= \sqrt{2} - 1\)Simplify

Check: \(\sqrt{2} - 1\approx 0.414\) and \(\tan(22.5^\circ)\approx 0.414\).

Example 6
Evaluating with the half-angle identities

Evaluate each expression. First find which unit-circle angle has the target as its half, then decide the sign.

ExpressionWork
(a) \(\sin(15^\circ)\)\(15^\circ = \dfrac{30^\circ}{2}\), and \(15^\circ\in\) QI, so +.
\(\sin(15^\circ) = \sqrt{\dfrac{1 - \cos 30^\circ}{2}} = \sqrt{\dfrac{1 - \sqrt{3}/2}{2}\cdot\dfrac{2}{2}} = \sqrt{\dfrac{2 - \sqrt{3}}{4}} = \dfrac{\sqrt{2 - \sqrt{3}}}{2}\)
(b) \(\cos\left(\dfrac{5\pi}{8}\right)\)\(\dfrac{5\pi}{8} = \dfrac{5\pi/4}{2}\), and \(\dfrac{5\pi}{8}\in\) QII (between \(\dfrac{\pi}{2}\) and \(\pi\)), cosine is negative, so −.
\(\cos\left(\dfrac{5\pi}{8}\right) = -\sqrt{\dfrac{1 + \cos(5\pi/4)}{2}} = -\sqrt{\dfrac{1 - \sqrt{2}/2}{2}\cdot\dfrac{2}{2}} = -\dfrac{\sqrt{2 - \sqrt{2}}}{2}\)

Compare with Lesson 16: \(\sin 15^\circ = \dfrac{\sqrt{6} - \sqrt{2}}{4}\approx 0.259\) and \(\dfrac{\sqrt{2-\sqrt{3}}}{2}\approx 0.259\). Same number, two different-looking forms.

Example 7
Two ways to the same answer

Evaluate \(\sin(105^\circ)\cos(105^\circ)\).

(a) Using half-angle identities, with \(105^\circ = \dfrac{210^\circ}{2}\) in QII (sine +, cosine −):

\(\sin(105^\circ) = \)\(+\sqrt{\dfrac{1 - \cos 210^\circ}{2}} = \sqrt{\dfrac{1 + \sqrt{3}/2}{2}} = \dfrac{\sqrt{2 + \sqrt{3}}}{2}\)
\(\cos(105^\circ) = \)\(-\sqrt{\dfrac{1 + \cos 210^\circ}{2}} = -\sqrt{\dfrac{1 - \sqrt{3}/2}{2}} = -\dfrac{\sqrt{2 - \sqrt{3}}}{2}\)
Product: \(-\dfrac{\sqrt{(2 + \sqrt{3})(2 - \sqrt{3})}}{4} = -\dfrac{\sqrt{4 - 3}}{4} = -\dfrac{1}{4}\)

(b) Using a double-angle identity: \(\sin\theta\cos\theta = \dfrac{1}{2}\sin(2\theta)\).

\(\sin(105^\circ)\cos(105^\circ) = \dfrac{1}{2}\sin(210^\circ) = \dfrac{1}{2}\left(-\dfrac{1}{2}\right) = -\dfrac{1}{4}\)

Both agree. Part (b) took one line, so look for a double-angle shortcut before reaching for the half-angle roots.
