Verifying Trigonometric Identities
Verifying is not solving

To verify an identity, we work on each side independently until both sides are shown to be the same expression.

We never solve. Moving terms across the equals sign, or squaring both sides, assumes the very thing we are trying to show.

Why? Start with the false statement \(-1 = 1\) and square both sides:

\(-1 = 1\)false
\((-1)^2 = (1)^2\)\(1 = 1\), which is true!

A true ending does not prove a true beginning, so a verification must never cross to the other side.

There are no fixed rules. Expect several failed attempts before one works.

Three Common Strategies
Starting points, not rules
  1. Rewrite all functions in terms of sine and cosine alone.
  2. Combine ratios using a common denominator (or split one ratio into two).
  3. Multiply by the conjugate, then apply a Pythagorean identity.

Keep these on hand while you work:

\(\tan\theta = \dfrac{\sin\theta}{\cos\theta}\)\(\cot\theta = \dfrac{\cos\theta}{\sin\theta}\)\(\sec\theta = \dfrac{1}{\cos\theta}\)\(\csc\theta = \dfrac{1}{\sin\theta}\)
\(\sin^2\theta + \cos^2\theta = 1\)\(1 + \cot^2\theta = \csc^2\theta\)\(\tan^2\theta + 1 = \sec^2\theta\)
Strategy 1
Rewrite in terms of sine and cosine alone

The reciprocal and ratio identities turn every function into sine and cosine, which usually opens up cancellation.

Example 1a. Verify \(\cot x\sec x = \csc x\). Work on the left side only.

StepReason
\(\cot x\sec x\)Starting side
\(\dfrac{\cos x}{\sin x}\cdot\dfrac{1}{\cos x}\)Ratio and reciprocal identities
\(\dfrac{1}{\sin x}\)Cancel \(\cos x\)
\(\csc x\)Reciprocal identity. Matches the right side.

Graph check: the solid and dashed curves land on top of each other wherever both sides are defined. A graph suggests an identity, but only the algebra above verifies it.

Example 1b

Example 1b. Verify \(\dfrac{\sin\theta}{\tan\theta}\cdot\dfrac{\sec\theta}{\cos\theta} = \dfrac{\tan\theta}{\sin\theta}\).

Which side looks messier? Start there, and leave the other side alone until the end.

StepReason
\(\dfrac{\sin\theta}{\tan\theta}\cdot\dfrac{\sec\theta}{\cos\theta}\)Starting side
\(\dfrac{\sin\theta}{\sin\theta/\cos\theta}\cdot\dfrac{1/\cos\theta}{\cos\theta}\)Rewrite \(\tan\) and \(\sec\)
\(\dfrac{\sin\theta\cos\theta}{\sin\theta}\cdot\dfrac{1}{\cos^2\theta}\)Simplify each complex fraction
\(\cos\theta\cdot\dfrac{1}{\cos^2\theta} = \dfrac{1}{\cos\theta}\)Cancel \(\sin\theta\), then one \(\cos\theta\)
\(\dfrac{\sin\theta/\cos\theta}{\sin\theta} = \dfrac{1}{\cos\theta}\)Now simplify the right side \(\dfrac{\tan\theta}{\sin\theta}\) too. Both sides equal \(\dfrac{1}{\cos\theta}\).

Graph check: the solid and dashed curves land on top of each other wherever both sides are defined. A graph suggests an identity, but only the algebra above verifies it.

Example 2
Squares and a Pythagorean identity

Verify \(\cos^2 x = 1 - \tan^2 x\cos^2 x\).

The right side has two functions and a subtraction. Which side do you work on?

StepReason
\(1 - \tan^2 x\cos^2 x\)Starting side (the right side)
\(1 - \dfrac{\sin^2 x}{\cos^2 x}\cdot\cos^2 x\)Rewrite \(\tan^2 x\)
\(1 - \sin^2 x\)Cancel \(\cos^2 x\)
\(\cos^2 x\)Pythagorean identity. Matches the left side.

Graph check: the solid and dashed curves land on top of each other wherever both sides are defined. A graph suggests an identity, but only the algebra above verifies it.

Strategy 2
Combine ratios using a common denominator

Given two ratios, combine them over a common denominator. At times it helps to split one ratio into two instead.

Example 3. Verify \(\sin x\,(\cot x + \tan x) = \sec x\).

StepReason
\(\sin x\,(\cot x + \tan x)\)Starting side
\(\sin x\left(\dfrac{\cos x}{\sin x} + \dfrac{\sin x}{\cos x}\right)\)Ratio identities
\(\cos x + \dfrac{\sin^2 x}{\cos x}\)Distribute \(\sin x\)
\(\dfrac{\cos^2 x}{\cos x} + \dfrac{\sin^2 x}{\cos x} = \dfrac{\cos^2 x + \sin^2 x}{\cos x}\)Common denominator \(\cos x\)
\(\dfrac{1}{\cos x} = \sec x\)Pythagorean identity, then reciprocal identity

Graph check: the solid and dashed curves land on top of each other wherever both sides are defined. A graph suggests an identity, but only the algebra above verifies it.

Example 4
Common denominator, then factor

Verify \(\dfrac{\sec\theta}{\sin\theta} - \dfrac{2\sin\theta}{\cos\theta} = \cot\theta - \tan\theta\).

StepReason
\(\dfrac{\sec\theta}{\sin\theta} - \dfrac{2\sin\theta}{\cos\theta}\)Starting side
\(\dfrac{1}{\sin\theta\cos\theta} - \dfrac{2\sin\theta}{\cos\theta}\)\(\sec\theta = 1/\cos\theta\)
\(\dfrac{1}{\sin\theta\cos\theta} - \dfrac{2\sin^2\theta}{\sin\theta\cos\theta}\)Common denominator \(\sin\theta\cos\theta\)
\(\dfrac{1 - 2\sin^2\theta}{\sin\theta\cos\theta} = \dfrac{\cos^2\theta + \sin^2\theta - 2\sin^2\theta}{\sin\theta\cos\theta}\)Replace \(1\) with \(\cos^2\theta + \sin^2\theta\)
\(\dfrac{\cos^2\theta - \sin^2\theta}{\sin\theta\cos\theta} = \dfrac{\cos\theta}{\sin\theta} - \dfrac{\sin\theta}{\cos\theta}\)Split the ratio into two
\(\cot\theta - \tan\theta\)Ratio identities. Matches the right side.

Graph check: the solid and dashed curves land on top of each other wherever both sides are defined. A graph suggests an identity, but only the algebra above verifies it.

Strategy 3
Multiply by the conjugate, then use a Pythagorean identity

A sum or difference such as \(1 + \sin x\) pairs with its conjugate \(1 - \sin x\), and \((a-b)(a+b) = a^2 - b^2\) produces a square to convert.

Example 5. Verify \((1 - \sin\theta)(1 + \sin\theta) = \dfrac{\cot^2\theta}{\csc^2\theta}\).

StepReason
\((1 - \sin\theta)(1 + \sin\theta)\)Starting side (already a conjugate pair)
\(1 - \sin^2\theta\)Difference of squares
\(\cos^2\theta\)Pythagorean identity
\(\dfrac{\cot^2\theta}{\csc^2\theta} = \dfrac{\cos^2\theta/\sin^2\theta}{1/\sin^2\theta} = \cos^2\theta\)Right side simplified separately. Both sides equal \(\cos^2\theta\).

Graph check: the solid and dashed curves land on top of each other wherever both sides are defined. A graph suggests an identity, but only the algebra above verifies it.

Example 6
The conjugate hides in the numerator

Verify \(\dfrac{\sin^2 x}{1 - \cos x} = 1 + \cos x\).

The denominator is a difference. Is there a way to use \(\sin^2 x\) to produce the conjugate \(1 + \cos x\)?

StepReason
\(\dfrac{\sin^2 x}{1 - \cos x}\)Starting side
\(\dfrac{1 - \cos^2 x}{1 - \cos x}\)Pythagorean identity: \(\sin^2 x = 1 - \cos^2 x\)
\(\dfrac{(1 - \cos x)(1 + \cos x)}{1 - \cos x}\)Factor as a difference of squares
\(1 + \cos x\)Cancel \(1 - \cos x\). Matches the right side.

The left side is undefined at \(x = 0, \pm 2\pi\) (a hole in the dashed curve is fine). An identity only needs to hold where both sides are defined.

Example 7
Multiply top and bottom by the conjugate

Verify \(\dfrac{1}{\sec x + \tan x} = \dfrac{1 - \sin x}{\cos x}\).

StepReason
\(\dfrac{1}{\sec x + \tan x}\)Starting side
\(\dfrac{1}{\frac{1}{\cos x} + \frac{\sin x}{\cos x}} = \dfrac{1}{\frac{1 + \sin x}{\cos x}} = \dfrac{\cos x}{1 + \sin x}\)Strategy 1, then Strategy 2
\(\dfrac{\cos x}{1 + \sin x}\cdot\dfrac{1 - \sin x}{1 - \sin x} = \dfrac{\cos x\,(1 - \sin x)}{1 - \sin^2 x}\)Multiply by the conjugate \(\dfrac{1 - \sin x}{1 - \sin x}\)
\(\dfrac{\cos x\,(1 - \sin x)}{\cos^2 x}\)Pythagorean identity
\(\dfrac{1 - \sin x}{\cos x}\)Cancel one \(\cos x\). Matches the right side.

Graph check: the solid and dashed curves land on top of each other wherever both sides are defined. A graph suggests an identity, but only the algebra above verifies it.
