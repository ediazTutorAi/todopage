Evaluating Trigonometric Functions with Reference Angles

Reference Angles
Definitions

For an angle \(\theta\), in standard position, we often consider a triangle with hypotenuse along the terminal side of \(\theta\) and base along the \(x\)-axis. A right triangle formed this way is called a reference triangle.

The acute angle formed by the hypotenuse and the \(x\)-axis is called the reference angle, typically denoted \(\theta_r\) or \(\theta'\).

The reference angle is always the small angle between the terminal side and the nearest part of the \(x\)-axis — never measured from the \(y\)-axis — and it's always positive and acute (between \(0°\) and \(90°\)).

Definition: Reference (Related) Angles
For a non-quadrantal angle \(\theta\)

For a non-quadrantal angle \(\theta\), in standard position, the reference angle is the positive acute angle formed by the terminal side of \(\theta\) and the \(x\)-axis.

"Non-quadrantal" means \(\theta\) doesn't land exactly on an axis (not a multiple of \(90°\)) — quadrantal angles (\(0°, 90°, 180°, 270°, \dots\)) have no reference angle.

Reference angle formula, by quadrant: QI: \(\theta_r = \theta\)   QII: \(\theta_r = 180° - \theta\)   QIII: \(\theta_r = \theta - 180°\)   QIV: \(\theta_r = 360° - \theta\) (or \(|\theta|\) if \(\theta\) is measured as negative)

Procedure: Finding the Reference Angle
For any non-quadrantal angle \(\theta\), in standard position

Step 1: If \(\theta > 360°\) or \(\theta < 0°\), find a coterminal angle by adding or subtracting \(360°\) as many times as needed to get an angle between \(0°\) and \(360°\).

Step 2: If the result from Step 1 is between \(0°\) and \(90°\), that result is \(\theta_r\). If not, subtract \(180°\) and continue to Step 3.

Step 3: If the result from Step 2 is between \(0°\) and \(90°\), that result is \(\theta_r\). If it's between \(-90°\) and \(0°\), \(\theta_r\) is its absolute value. If neither, subtract \(180°\) and repeat this step.

Take a moment to think about why this procedure works — each subtraction of \(180°\) or \(360°\) lands on a coterminal or supplementary angle, walking \(\theta\) back toward the nearest \(x\)-axis.

Example 2 (a)–(c)
Applying the procedure

Given \(\theta\), find \(\theta_r\).

(a) \(\theta = -32°\)

\(\theta\) is already between \(-90°\) and \(0°\), so \(\theta_r = |-32°| = 32°\)

(b) \(\theta = 197°\)

\(197° - 180° = 17°\), between \(0°\) and \(90°\), so \(\theta_r = 17°\)

(c) \(\theta = 288°\)

\(288° - 180° = 108°\); not between \(0°\) and \(90°\), so subtract again: \(108° - 180° = -72°\), so \(\theta_r = |-72°| = 72°\)

Example 2 (d)–(f)
Applying the procedure

(d) \(\theta = 682°\)

\(682° - 360° = 322°\); \(322° - 180° = 142°\); \(142° - 180° = -38°\), so \(\theta_r = 38°\)

(e) \(\theta = -730°\)

\(-730° + 360° = -370°\); \(-370° + 360° = -10°\), between \(-90°\) and \(0°\), so \(\theta_r = |-10°| = 10°\)

(f) \(\theta = 900°\)

\(900° - 360° = 540°\); \(540° - 360° = 180°\) — a quadrantal angle, so \(\theta_r\) is undefined (DNE)

Theorem: Reference Angle Theorem
Same reference angle → same trig values, up to sign

Consider an angle \(\theta\) with reference angle \(\theta_r\), and its "mirror" angles in the other three quadrants sharing that same \(\theta_r\). Each terminal side meets the circle at a point with the same coordinate magnitudes — only the signs of \(x\) and \(y\) change by quadrant:

QII: \((-a,\ b)\)QI: \((a,\ b)\)
QIII: \((-a,\ -b)\)QIV: \((a,\ -b)\)

Theorem: Let \(\theta\) be any non-quadrantal angle, in standard position, with reference angle \(\theta_r\), and let \(f\) be any trigonometric function. Then \(|f(\theta)| = f(\theta_r)\).

That is, \(f(\theta)\) is equal to \(f(\theta_r)\), except for a possible change in sign — that sign is determined by the quadrant for the angle \(\theta\).

This sign is exactly the ASTC pattern from Lesson 04: All positive in QI, Sine (and csc) positive in QII, Tangent (and cot) positive in QIII, Cosine (and sec) positive in QIV.

Example 3 (a)–(b)
Evaluate using reference angles

(a) \(\cos(210°)\)

\(210° \in\) QIII, where cosine is negative. \(\theta_r = 210° - 180° = 30°\), so \(\cos(210°) = -\cos(30°) = -\dfrac{\sqrt{3}}{2}\)

(b) \(\sin(480°)\)

\(480° - 360° = 120°\) coterminal, shown above.

\(480°\) is coterminal with \(120° \in\) QII, where sine is positive. \(\theta_r = 180° - 120° = 60°\), so \(\sin(480°) = \sin(60°) = \dfrac{\sqrt{3}}{2}\)

Example 3 (c)–(d)
Evaluate using reference angles

(c) \(\tan(765°)\)

\(765° - 720° = 45°\) coterminal, shown above.

\(765°\) is coterminal with \(45° \in\) QI, where tangent is positive. \(\theta_r = 45°\), so \(\tan(765°) = \tan(45°) = 1\)

(d) \(\csc(-225°)\)

\(-225° + 360° = 135°\) coterminal, shown above.

\(-225°\) is coterminal with \(135° \in\) QII, where cosecant (reciprocal of sine) is positive. \(\theta_r = 180° - 135° = 45°\), so \(\csc(-225°) = \csc(45°) = \dfrac{1}{\sin(45°)} = \dfrac{2}{\sqrt{2}} = \sqrt{2}\)

Example 4
Solve for \(\theta\), given \(0° \le \theta < 360°\)

Let \(\theta\) be an angle in standard position, with \(0° \le \theta < 360°\). Find all possible \(\theta\)-values that satisfy each expression.

(a) \(\cos(\theta) = -\dfrac{\sqrt{3}}{2}\)

Negative, so \(\theta \in\) QII or QIII. Since \(\cos(30°) = \dfrac{\sqrt{3}}{2}\), \(\theta_r = 30°\), giving \(\theta = 180° - 30° = 150°\) or \(\theta = 180° + 30° = 210°\)

(b) \(\tan(\theta) = \sqrt{3}\)

Positive, so \(\theta \in\) QI or QIII. Since \(\tan(60°) = \sqrt{3}\), \(\theta_r = 60°\), giving \(\theta = 60°\) or \(\theta = 180° + 60° = 240°\)

(c) \(\csc(\theta) = \sqrt{2}\)

\(\sin(\theta) = \dfrac{1}{\sqrt{2}} = \dfrac{\sqrt{2}}{2} > 0\), so \(\theta \in\) QI or QII. Since \(\sin(45°) = \dfrac{\sqrt{2}}{2}\), \(\theta_r = 45°\), giving \(\theta = 45°\) or \(\theta = 180° - 45° = 135°\)

Looking Ahead
From reference angles to the unit circle

Reference angles are a useful tool for evaluating trig functions by hand. Soon we'll build an even more efficient resource: the unit circle, which encodes these same reference-angle/quadrant-sign ideas directly as \((\cos\theta, \sin\theta)\) coordinates around a circle of radius \(1\).

Constructing the unit circle takes some practice up front, but pays off with faster, more reliable evaluations than re-deriving a reference triangle each time.
