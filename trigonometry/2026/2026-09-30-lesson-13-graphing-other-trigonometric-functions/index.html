Graphing Other Trigonometric Functions

Graphing Other Trigonometric Functions
Tangent, cotangent, secant, and cosecant

We already graphed sine and cosine by following the angle around the unit circle. The other four functions are built from those two, so the same unit circle builds their graphs too.

Recall each definition in terms of sine and cosine.

\(\tan\theta\)\(\dfrac{\sin\theta}{\cos\theta} = \dfrac{y}{x}\)
\(\cot\theta\)\(\dfrac{\cos\theta}{\sin\theta} = \dfrac{x}{y}\)
\(\sec\theta\)\(\dfrac{1}{\cos\theta} = \dfrac{1}{x}\)
\(\csc\theta\)\(\dfrac{1}{\sin\theta} = \dfrac{1}{y}\)

Each of these is a fraction, so each one breaks when its denominator is zero.

When is each function undefined?

\(\tan\theta\) and \(\sec\theta\)when \(\cos\theta = 0\), at \(\theta = \dfrac{\pi}{2} + \pi k\)
\(\cot\theta\) and \(\csc\theta\)when \(\sin\theta = 0\), at \(\theta = \pi k\)

Those input values become the vertical asymptotes of each graph.

Graphing Tangent
Building \(y = \tan x\) from the unit circle

We use the angle \(\theta\) as the input, graphed along the horizontal axis. The output is the \(y/x\) value from the unit circle.

Press Play, or drag \(\theta\). The ray through the point meets the line \(x = 1\) at height \(\tan\theta\), because \(\dfrac{y}{x} = \dfrac{\text{height}}{1}\). That height is the value plotted. Watch what happens near \(\dfrac{\pi}{2}\).

Why does the graph shoot off to infinity at \(\dfrac{\pi}{2}\)?

At \(\dfrac{\pi}{2}\) the point is \((0, 1)\), so \(x = 0\) and \(\dfrac{y}{x}\) is undefined. The ray is now parallel to the line \(x = 1\) and never meets it. Just before it, the ray meets the line very high up.

Why does the graph come back from \(-\infty\) just after \(\dfrac{\pi}{2}\)?

Past \(\dfrac{\pi}{2}\), \(x\) is negative while \(y\) is positive, so \(\dfrac{y}{x}\) is a large negative number that shrinks toward \(0\).

Graphing Cotangent
Building \(y = \cot x\) from the unit circle

Cotangent uses the reciprocal ratio, \(\dfrac{x}{y}\). The ray now meets the horizontal line \(y = 1\), and the horizontal distance it lands from the center is \(\cot\theta\).

Press Play. The asymptotes show up where the ray goes parallel to \(y = 1\), at \(0, \pi, 2\pi\). Notice how the curve falls as \(\theta\) grows.

Where does the cotangent graph cross the \(x\)-axis?

Where \(x = 0\) on the circle, at \(\dfrac{\pi}{2}\) and \(\dfrac{3\pi}{2}\). The fraction \(\dfrac{x}{y}\) is \(0\) when its numerator is \(0\). These are exactly the asymptotes of tangent.

Combining Transformations
Summary of transformations for tangent and cotangent

Consider \(y = a\tan[b(x + c)] + d\) or \(y = a\cot[b(x + c)] + d\), with \(b > 0\).

Vertical stretch / compressionThe value \(|a|\) is the vertical stretch or compression. If \(a < 0\), the graph is reflected across the horizontal axis.
PeriodThe value \(\dfrac{\pi}{b}\) is the period.
Horizontal shiftIf \(c > 0\), the graph is shifted left \(c\) units. If \(c < 0\), it is shifted right \(|c|\) units. (Some texts call this the phase shift.)
Vertical shiftIf \(d > 0\), the graph is shifted up \(d\) units. If \(d < 0\), it is shifted down \(|d|\) units.

The only change from sine and cosine: the period is \(\pi / b\), not \(2\pi / b\), because tangent and cotangent repeat twice as fast.

Graphing Secant and Cosecant
Reciprocals of cosine and sine

After practice with sine and cosine, the graphs of cosecant and secant are closely related. They are reciprocals, so we use what we know about sine and cosine. When asked for a sketch, always begin with the related sine or cosine function first.

Complete each statement.

If \(\sin\theta = 1\), then \(\csc\theta =\)\(1\)If \(\cos\theta = 1\), then \(\sec\theta =\)\(1\)
If \(\sin\theta = -1\), then \(\csc\theta =\)\(-1\)If \(\cos\theta = -1\), then \(\sec\theta =\)\(-1\)
If \(\sin\theta = 0\), then \(\csc\theta =\)undefinedIf \(\cos\theta = 0\), then \(\sec\theta =\)undefined

What happens to \(\csc\theta\) when \(\sin\theta\) is a small positive number like \(0.01\)?

\(\dfrac{1}{0.01} = 100\), a huge value. As \(\sin\theta \to 0\) the reciprocal grows without bound, which is the asymptote.

Recipe and Practice
Graphing the four reciprocal-style functions
  1. Tangent and cotangent: mark the midline \(y = d\), the center point, and the asymptotes half a period either side. Period \(= \dfrac{\pi}{b}\), step \(= \dfrac{\text{period}}{4}\). Plot one step left and right of the center, then draw one branch.
  2. Secant and cosecant: sketch the related cosine or sine first (dashed), period \(\dfrac{2\pi}{b}\). Draw asymptotes where it crosses the midline, mark vertices where it peaks or bottoms out, then draw branches away from the midline.
