Translating Sine and Cosine Graphs
Sliding a graph up, down, left, and right

Like any function, the graphs of sine and cosine (and the other four trigonometric functions) can be translated up, down, left, and right using addition and subtraction.

Press Play: watch the curve slide onto its new position, one translation at a time. The chips above the graph light up for whichever part of the rule is moving.

Vertical Translations
Important info

Given the value \(d > 0\) and any function \(f(x)\), the graph of \(y = f(x) + d\) is a translation \(d\) units upward from the graph of \(y = f(x)\). Likewise, the graph of \(y = f(x) - d\) is a translation \(d\) units downward.

Drag \(d\) both ways. Every red arrow is the same length, exactly \(|d|\), and always vertical.

Horizontal Translations
Important info

Given the value \(c > 0\) and any function \(f(x)\), the graph of \(y = f(x + c)\) is a translation \(c\) units left from the graph of \(y = f(x)\). Likewise, the graph of \(y = f(x - c)\) is a translation \(c\) units right.

Drag \(c\). Adding moves the graph left and subtracting moves it right, the opposite of what the sign seems to say. Every red arrow is horizontal and exactly \(|c|\) long.

Why does adding \(c\) move the graph left?

The point that used to sit at \(x = 0\) now needs \(x + c = 0\) to give the same output, so it lands at \(x = -c\). Every point arrives \(c\) units earlier.

Combining Transformations
Summary of transformations

Consider \(y = a\sin[b(x + c)] + d\) or \(y = a\cos[b(x + c)] + d\), with \(b > 0\).

AmplitudeThe value \(|a|\) is the amplitude. If \(a < 0\), the graph is reflected across the sinusoidal axis.
PeriodThe value \(2\pi / b\) is the period.
Horizontal shiftIf \(c > 0\), the graph is shifted left \(c\) units. If \(c < 0\), it is shifted right \(|c|\) units. (Some texts call this the phase shift.)
Vertical shiftIf \(d > 0\), the graph is shifted up \(d\) units. If \(d < 0\), it is shifted down \(|d|\) units.

Factor Out \(b\) First
Why \(\sin(2\theta + \pi)\) does not shift by \(\pi\)

The shift \(c\) only reads correctly when the inside looks like \(b(x + c)\). Rewrite \(\sin(2x + \pi)\) by factoring out the \(2\):

\(\sin(2x + \pi) = \sin\left(2\left(x + \dfrac{\pi}{2}\right)\right)\)

Press Play: the period squeezes first, then the inside term \(\pi\) slides in. The shift chip reports \(c \div b\), the true distance moved. Then drag \(b\) and \(c\) yourself.

Complications Involving Horizontal Translation
Choosing a horizontal scale

Graphing a trigonometric function with a horizontal translation can be challenging, and choosing a good horizontal scale is often the problem. Weigh three things:

  • the period,
  • the horizontal spacing between points of interest (maximums, minimums, intercepts), and
  • the amount of horizontal translation.

One good practice: write each of these quantities using a common denominator, then let that denominator set the tick spacing.

Watch for it in the next two examples: every tick on the axis is one step, and the shift is a whole number of steps.

Recipe and Practice
Graphing \(y = a\sin[b(x + c)] + d\) or \(y = a\cos[b(x + c)] + d\)
  1. Factor so the inside reads \(b(x + c)\).
  2. Sinusoidal axis: draw \(y = d\).
  3. Amplitude: mark \(y = d + |a|\) and \(y = d - |a|\). If \(a < 0\), the pattern flips.
  4. Period and step: period \(= \dfrac{2\pi}{b}\), step \(= \dfrac{\text{period}}{4}\), using a common denominator.
  5. Shift: the cycle starts at \(x = -c\).
  6. Five points, one smooth curve, then repeat.

Practice: set the sliders to \(a = -2\), \(b = 2\), \(c = \dfrac{\pi}{4}\), \(d = 1\), and predict the five key points before checking them on the graph.
