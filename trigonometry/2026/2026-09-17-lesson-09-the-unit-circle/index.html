The Unit Circle

The Unit Circle
The most valuable reference tool in this course

The unit circle is a circle of radius \(1\) centered at the origin. Every point on it corresponds to an angle \(\theta\) in standard position, and to a pair of coordinates \((\cos\theta, \sin\theta)\).

Much like the Quadrant I Chart, the unit circle is reference material you'll use for the rest of this course. It does not need to be memorized — with a little practice, you can reconstruct it from just two facts: how to divide a circle into \(6\) pieces, and how to divide it into \(4\).

Drag the blue point around the circle in every diagram below — the panel to its right updates live with the angle and all six trig function values.

Constructing the Unit Circle
Click "Build →" to add each step in turn

Step 1: Draw the \(xy\)-axes and a circle of radius \(1\) centered at the origin. Mark \((-1,0)\) as \(\pi\), a reminder that \(180° = \pi\) radians.

Steps 2–3: Since \(\pi/6\) is an important angle, divide the upper semicircle into \(6\) equal pieces, draw chords through the origin connecting opposite points, and count off the marked points: \(\pi/6, 2\pi/6, 3\pi/6, 4\pi/6, \ldots\)

Step 4: Repeat the process, this time dividing the upper semicircle into \(4\) equal pieces using \(\pi/4\). Together, the two families give \(16\) points around the circle.

Step 5: Each point along the circle corresponds to a cosine and a sine value: \((x, y) = (\cos\theta, \sin\theta)\). Using the Quadrant I Chart, label each Quadrant I point this way.

Step 6 (optional): Label the remaining points using the Quadrant I values and symmetry — the magnitudes repeat every quadrant, only the signs of \(x\) and \(y\) change. This labeling can wait until you actually need it.

The "Build →" button adds one step at a time, in order; once every step is showing it becomes "↺ Reset." Drag the point around at any stage — the readout panel keeps updating live, even mid-construction.

Example 1
Evaluate each expression using the unit circle

(a) \(\sin\left(\dfrac{5\pi}{6}\right)\) \(= \dfrac{1}{2}\) (the \(y\)-value at \(150°\))

(b) \(\cos(225°)\) \(= -\dfrac{\sqrt{2}}{2}\) (the \(x\)-value at \(225°\))

(c) \(\tan\left(\dfrac{11\pi}{6}\right)\) \(= \dfrac{-1/2}{\sqrt{3}/2} = -\dfrac{1}{\sqrt{3}} = -\dfrac{\sqrt{3}}{3}\) (\(y\)-value over \(x\)-value at \(330°\))

(d) \(\csc\left(\dfrac{4\pi}{3}\right)\) \(= \dfrac{1}{\sin(4\pi/3)} = \dfrac{1}{-\sqrt{3}/2} = -\dfrac{2\sqrt{3}}{3}\)

(e) \(\cot(180°)\) \(= \dfrac{x}{y} = \dfrac{-1}{0}\), undefined

Drag the point to \(150°\), \(225°\), \(330°\), \(240°\), and \(180°\) in turn — the readout panel confirms each value above as you go.

Example 2
Coterminal angles not already on the circle

Some special angles yield exact values but fall outside a single revolution. Add or subtract \(360°\) (or \(2\pi\)) as many times as needed to land on a coterminal angle that is on the unit circle.

(a) \(\sin\left(-\dfrac{5\pi}{6}\right)\) \(-\dfrac{5\pi}{6} + 2\pi = \dfrac{7\pi}{6}\), so this \(= \sin\left(\dfrac{7\pi}{6}\right) = -\dfrac{1}{2}\)

(b) \(\cos(-690°)\) \(-690° + 360° = -330°\), \(-330° + 360° = 30°\), so this \(= \cos(30°) = \dfrac{\sqrt{3}}{2}\)

(c) \(\tan(5\pi)\) \(5\pi - 2\pi = 3\pi\), \(3\pi - 2\pi = \pi\), so this \(= \tan(\pi) = \dfrac{0}{-1} = 0\)

(d) \(\csc\left(\dfrac{17\pi}{6}\right)\) \(\dfrac{17\pi}{6} - 2\pi = \dfrac{5\pi}{6}\), so this \(= \csc\left(\dfrac{5\pi}{6}\right) = \dfrac{1}{1/2} = 2\)

(e) \(\sec(1290°)\) \(1290° - 360° = 930°\), \(930° - 360° = 570°\), \(570° - 360° = 210°\), so this \(= \sec(210°) = \dfrac{1}{-\sqrt{3}/2} = -\dfrac{2\sqrt{3}}{3}\)

The diagram above starts at \(-690°\) (part (b)) — drag it around; the panel shows the raw angle, how many full rotations get removed, and the resulting angle already on the circle.

Example 3 (a)
Given one ratio, find the other five

Assume \(0 \le \theta < 2\pi\). Given \(\cos(\theta) = -\dfrac{1}{2}\), find the values of the other five trigonometric functions.

The dashed line marks every point with \(x = -1/2\) — drag the point to each of its two intersections with the circle (\(120°\) and \(240°\)).

Two angles satisfy \(\cos\theta = -1/2\): \(\theta = 2\pi/3\) (\(120°\)) and \(\theta = 4\pi/3\) (\(240°\)). Since \(\cos\theta\) alone doesn't pin down the quadrant, \(\sin\theta = \pm\sqrt{3}/2\), and every ratio built from it carries the same \(\pm\): \(\sec\theta = -2\), \(\csc\theta = \pm 2\sqrt{3}/3\), \(\tan\theta = \pm\sqrt{3}\), \(\cot\theta = -\sqrt{3}/3\).
Example 3 (b)
Two conditions pin down a single angle

Given \(\sin(\theta) = -\dfrac{\sqrt{3}}{2}\) and \(\cos(\theta) > 0\), find \(\tan(\theta)\), if possible.

The dashed line marks \(y = -\sqrt{3}/2\) — it crosses the circle twice, but only one crossing also has \(\cos\theta > 0\) (positive \(x\)). Drag to find it.

\(y = -\sqrt3/2\) meets the circle at \(240°\) and \(300°\); only \(300°\) (\(5\pi/3\)) has positive \(x\). There, \(\tan(5\pi/3) = \dfrac{-\sqrt3/2}{1/2} = -\sqrt3\).
Example 3 (c)
A squared condition gives four solutions

Find the exact value(s) for \(\theta\) given that \(\cos^2(\theta) = \dfrac{1}{2}\).

\(\cos\theta = \pm\sqrt{1/2} = \pm\sqrt2/2\) — two dashed lines, each crossing the circle twice, for four solutions total. Drag to each in turn.

\(\cos\theta = \sqrt2/2\) at \(\pi/4\) and \(7\pi/4\); \(\cos\theta = -\sqrt2/2\) at \(3\pi/4\) and \(5\pi/4\). So \(\theta \in \{\pi/4,\ 3\pi/4,\ 5\pi/4,\ 7\pi/4\}\).
Looking Ahead
One diagram, every trig identity to come

Notice the readout panel above always grouped values that behave the same way: \(\sin\)/\(\csc\), \(\cos\)/\(\sec\), and \(\tan\)/\(\cot\) are always reciprocals of each other, and \(\tan\theta\) is always \(\sin\theta / \cos\theta\). These reciprocal and quotient relationships — along with \(\sin^2\theta + \cos^2\theta = 1\), visible in the fact that every point you dragged stayed exactly distance \(1\) from the origin — are exactly the identities the next lesson makes precise.
