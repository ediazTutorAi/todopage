Divergence and Curl

Divergence
Definition, Example 6.48 and Checkpoint 6.40
Definition: divergence

If \(\vec F=\langle P,Q,R\rangle\) is a vector field in \(\mathbb{R}^3\) and \(P_x\), \(Q_y\), and \(R_z\) all exist, then the divergence of \(\vec F\) is defined by $$\operatorname{div}\vec F=P_x+Q_y+R_z=\frac{\partial P}{\partial x}+\frac{\partial Q}{\partial y}+\frac{\partial R}{\partial z}=\nabla\cdot\vec F.$$

If \(\vec F=\langle P,Q\rangle\) is a vector field in \(\mathbb{R}^2\), then \(\operatorname{div}\vec F=P_x+Q_y=\nabla\cdot\vec F\).

The divergence of a vector field is not a vector field, but a scalar function.

Drag the red point. The orange circle is carried by the flow for a time \(\tau\) (slider): the divergence says whether it grows or shrinks.

Using Divergence
Theorems 6.14, 6.15 and Examples 6.49 to 6.51, Checkpoints 6.41, 6.42
Theorem 6.14: Divergence of a Source-Free Vector Field

If \(\vec F=\langle P,Q\rangle\) is a source-free continuous vector field with differentiable component functions, then \(\operatorname{div}\vec F=0\).

Theorem 6.15: Divergence Test for Source-Free Vector Fields

Let \(\vec F=\langle P,Q\rangle\) be a continuous vector field with differentiable component functions with a domain that is simply connected. Then, \(\operatorname{div}\vec F=0\) if and only if \(\vec F\) is source free.

Flux form of Green's theorem, since \(P_x+Q_y=\operatorname{div}\vec F\): $$\int_C\vec F\cdot\vec N\,ds=\iint_D\operatorname{div}\vec F\,dA.$$

Example 6.49. Is it possible for \(\vec F(x,y)=\langle x^2y,\ y-xy^2\rangle\) to be a magnetic field? (Gauss's law for magnetism: \(\nabla\cdot\vec B=0\).)\(\operatorname{div}\vec F=2xy+1-2xy=1\neq0\), so \(\vec F\) cannot model a magnetic field.
Example 6.50. Is \(\vec F(x,y)=\langle x^2y,\ 5-xy^2\rangle\) source free?The domain \(\mathbb{R}^2\) is simply connected and \(\vec F\) is continuous with differentiable components. \(\operatorname{div}\vec F=2xy-2xy=0\), so \(\vec F\) is source free by Theorem 6.15.
Checkpoint 6.41. \(\vec F(x,y)=\langle-ay,bx\rangle\), \(a,b>0\), a rotational field. Is it source free?\(\operatorname{div}\vec F=\dfrac{\partial}{\partial x}(-ay)+\dfrac{\partial}{\partial y}(bx)=0\). Yes.
Example 6.51. \(\vec v(x,y)=\langle-xy,\ y\rangle\), \(y>0\), models a fluid flow. Is more fluid flowing into \((1,4)\) than out?\(\operatorname{div}\vec v=-y+1\). At \((1,4)\): \(-4+1=-3<0\), so more fluid is flowing in than out.
Checkpoint 6.42. For the same \(\vec v\), find all points \(P\) where the fluid flowing in equals the fluid flowing out.\(\operatorname{div}\vec v=1-y=0\) exactly when \(y=1\): every point of the line \(y=1\).
Curl
Definition, Examples 6.52, 6.53 and Checkpoint 6.43
Definition: curl

If \(\vec F=\langle P,Q,R\rangle\) is a vector field in \(\mathbb{R}^3\) and \(P_x,P_y,P_z,Q_x,Q_y,Q_z,R_x,R_y,R_z\) all exist, then the curl of \(\vec F\) is defined by $$\operatorname{curl}\vec F=(R_y-Q_z)\,\mathbf i+(P_z-R_x)\,\mathbf j+(Q_x-P_y)\,\mathbf k=\nabla\times\vec F=\begin{vmatrix}\mathbf i&\mathbf j&\mathbf k\\ \frac{\partial}{\partial x}&\frac{\partial}{\partial y}&\frac{\partial}{\partial z}\\ P&Q&R\end{vmatrix}.$$

If \(\vec F=\langle P,Q\rangle\) is a vector field in \(\mathbb{R}^2\), then \(\operatorname{curl}\vec F=(Q_x-P_y)\,\mathbf k\).

The curl of a vector field is a vector field, in contrast to divergence.

Circulation form of Green's theorem, since \(\operatorname{curl}\vec F\cdot\mathbf k=Q_x-P_y\): $$\int_C\vec F\cdot d\vec r=\iint_D\operatorname{curl}\vec F\cdot\mathbf k\,dA.$$

The orange circle turns when the curl is not zero (the dot marks one point of it).

Example 6.52. Curl of \(\vec F=\langle x^2z,\ e^y+xz,\ xyz\rangle\).\(\operatorname{curl}\vec F=(R_y-Q_z)\mathbf i+(P_z-R_x)\mathbf j+(Q_x-P_y)\mathbf k=(xz-x)\,\mathbf i+(x^2-yz)\,\mathbf j+z\,\mathbf k\)
Checkpoint 6.43. Curl of \(\vec F=\langle\sin x\cos z,\ \sin y\sin z,\ \cos x\cos y\rangle\) at \((0,\tfrac\pi2,\tfrac\pi2)\).\(\operatorname{curl}\vec F=(-\cos x\sin y-\sin y\cos z)\,\mathbf i+(-\sin x\sin z+\sin x\cos y)\,\mathbf j\). At \((0,\tfrac\pi2,\tfrac\pi2)\): \(-\mathbf i\), that is \(\langle-1,0,0\rangle\).
Example 6.53. Curl of \(\vec F=\langle P,Q\rangle=\langle y,0\rangle\). (All vectors are parallel to the \(x\)-axis. Zero spin?)\(\operatorname{curl}\vec F=(Q_x-P_y)\,\mathbf k=-\mathbf k\neq\vec 0\). A paddlewheel in the first quadrant turns clockwise (negative): the larger vectors at the top of the wheel make it rotate.

Fields With No Spin
Example 6.54 and Checkpoint 6.44

The gravitational force that object 1 (mass \(m_1\), at the origin) exerts on object 2 (mass \(m_2\)) is the field $$\vec F(x,y,z)=-Gm_1m_2\Big\langle\frac{x}{(x^2+y^2+z^2)^{3/2}},\ \frac{y}{(x^2+y^2+z^2)^{3/2}},\ \frac{z}{(x^2+y^2+z^2)^{3/2}}\Big\rangle.$$

Example 6.54. Show that a gravitational field has no spin.Let \(P=\dfrac{x}{r^3}\), \(Q=\dfrac{y}{r^3}\), \(R=\dfrac{z}{r^3}\) with \(r^2=x^2+y^2+z^2\). Then \(R_y=-\dfrac{3yz}{r^5}=Q_z\), \(P_z=-\dfrac{3xz}{r^5}=R_x\), \(Q_x=-\dfrac{3xy}{r^5}=P_y\). So \(\operatorname{curl}\vec F=\vec 0\): the field has no spin.
Checkpoint 6.44. \(\vec v(x,y)=\Big\langle\dfrac{-y}{x^2+y^2},\ \dfrac{x}{x^2+y^2}\Big\rangle\) models a flow. Show that a leaf dropped into this fluid does not rotate.\(Q_x=\dfrac{y^2-x^2}{(x^2+y^2)^2}\) and \(P_y=\dfrac{y^2-x^2}{(x^2+y^2)^2}\), so \(\operatorname{curl}\vec v=(Q_x-P_y)\mathbf k=\vec 0\). The leaf circles the origin but does not spin.
Divergence of a Curl
Theorem 6.16, Example 6.55 and Checkpoint 6.45
Theorem 6.16: Divergence of the Curl

Let \(\vec F=\langle P,Q,R\rangle\) be a vector field in \(\mathbb{R}^3\) such that the component functions all have continuous second-order partial derivatives. Then, $$\operatorname{div}\operatorname{curl}(\vec F)=\nabla\cdot(\nabla\times\vec F)=0.$$

ProofBy Clairaut's theorem, \(\operatorname{div}\operatorname{curl}\vec F=R_{yx}-Q_{zx}+P_{zy}-R_{xy}+Q_{xz}-P_{yz}=0\).
Example 6.55. Show that \(\vec F(x,y,z)=e^x\mathbf i+yz\,\mathbf j+xz^2\mathbf k\) is not the curl of another vector field.The domain is \(\mathbb{R}^3\) and the second-order partials are continuous. \(\operatorname{div}\vec F=e^x+z+2xz\neq0\). If \(\vec F=\operatorname{curl}\vec G\), then \(\operatorname{div}\vec F=\operatorname{div}\operatorname{curl}\vec G=0\). So \(\vec F\) is not the curl of any vector field.
Checkpoint 6.45. Can \(\vec G(x,y,z)=\langle\sin x,\ \cos y,\ \sin(xyz)\rangle\) be the curl of a vector field?\(\operatorname{div}\vec G=\cos x-\sin y+xy\cos(xyz)\neq0\) (at \((0,0,0)\) it equals \(1\)). So no.
Curl Test and Laplace's Equation
Theorems 6.17, 6.18 and Examples 6.56, 6.57, Checkpoint 6.46
Theorem 6.17: Curl of a Conservative Vector Field

If \(\vec F=\langle P,Q,R\rangle\) is conservative, then \(\operatorname{curl}\vec F=\vec 0\). (Equivalently, \(\nabla\times\nabla f=\vec 0\).)

Theorem 6.18: Curl Test for a Conservative Field

Let \(\vec F=\langle P,Q,R\rangle\) be a vector field in space on a simply connected domain. If \(\operatorname{curl}\vec F=\vec 0\), then \(\vec F\) is conservative.

Laplace operator

\(\operatorname{div}(\nabla f)=\nabla\cdot(\nabla f)=f_{xx}+f_{yy}+f_{zz}=\nabla^2 f\). Laplace's equation is \(\nabla^2 f=0\); a function satisfying it is harmonic. The potential function of an electrostatic field in a region with no static charge is harmonic.

Example 6.56. Use the curl to decide whether \(\vec F(x,y,z)=\langle yz,\ xz,\ xy\rangle\) is conservative.The domain \(\mathbb{R}^3\) is simply connected. \(\operatorname{curl}\vec F=(x-x)\mathbf i+(y-y)\mathbf j+(z-z)\mathbf k=\vec 0\). So \(\vec F\) is conservative.
Example 6.57. Can \(f(x,y)=x^2+x-y\) be the potential function of an electrostatic field in a region of \(\mathbb{R}^2\) free of static charge?\(f_{xx}=2\) and \(f_{yy}=0\), so \(f_{xx}+f_{yy}\neq0\). \(f\) is not harmonic, so it cannot.
Checkpoint 6.46. Same question for \(f(x,y)=x^2-y^2+x\).\(f_{xx}+f_{yy}=2-2=0\). Yes, it is harmonic, so it is possible.
