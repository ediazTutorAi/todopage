Vector-Valued Functions and Space Curves

MATH 2326 · Dr. Esteban Diaz
3.1 Vector-Valued Functions
Definition
A vector-valued function is a function whose domain is a set of real numbers and whose range is a set of vectors. In the plane, $$\mathbf{r}(t) = f(t)\mathbf{i} + g(t)\mathbf{j} = \langle f(t),\,g(t)\rangle,$$ and in space, $$\mathbf{r}(t) = f(t)\mathbf{i} + g(t)\mathbf{j} + h(t)\mathbf{k} = \langle f(t),\,g(t),\,h(t)\rangle.$$ The real-valued functions $f$, $g$, $h$ are the component functions of $\mathbf{r}$, and $t$ is the parameter — often thought of as time. The domain of $\mathbf{r}$ is the intersection of the domains of $f$, $g$, and $h$.
Example 3.1
Evaluating a Vector-Valued Function
Let $\mathbf{r}(t) = 4\cos t\,\mathbf{i} + 3\sin t\,\mathbf{j}$.
  • $\mathbf{r}(0) = $ \(4\mathbf{i}\)
  • $\mathbf{r}(\pi/2) = $ \(3\mathbf{j}\)
  • $\mathbf{r}(2\pi/3) = $ \(-2\mathbf{i}+\tfrac{3\sqrt3}{2}\mathbf{j}\)
Cosine and sine are defined for every real number, so the domain of $\mathbf{r}$ is all real numbers.
Example 3.1 (continued)
A Restricted Domain
Now let $\mathbf{r}(t) = 3\tan t\,\mathbf{i} + 4\sec t\,\mathbf{j} + 5t\,\mathbf{k}$.
  • $\mathbf{r}(0) = $ \(4\mathbf{j}\)
  • $\mathbf{r}(\pi/2)$ is undefined
  • $\mathbf{r}(2\pi/3) = $ \(-3\sqrt3\,\mathbf{i} - 8\mathbf{j} + \tfrac{10\pi}{3}\mathbf{k}\)
$\tan t$ and $\sec t$ are undefined wherever $\cos t = 0$, so the domain is \(\left\{\, t \;\Big|\; t \neq \dfrac{(2n+1)\pi}{2},\ n \in \mathbb{Z} \,\right\}\)
Example 3.2
Graphing a Vector-Valued Function — Same Curve, Different Speed
$\mathbf{r}(t) = 4\cos t\,\mathbf{i}+3\sin t\,\mathbf{j}$ for $0\le t\le 2\pi$ traces out an ellipse with semi-axes $4$ (along $x$) and $3$ (along $y$) once around, since $x=4\cos t$, $y=3\sin t$ satisfy $x^2/16+y^2/9=1$. $$\mathbf{r}(t) = 4\cos 2t\,\mathbf{i}+3\sin 2t\,\mathbf{j}, \qquad 0\le t \le \pi$$ traces the same ellipse — just twice as fast, since doubling the angular rate means $t$ only has to run to $\pi$ to complete one full loop. A vector-valued function records both the shape of a curve and the speed/direction it's traced with; two different functions can share a shape but not a parametrization.
Example 3.2 (continued)
A Helix
Adding a linearly increasing $\mathbf{k}$-component lifts the circle into a spiral in space: $$\mathbf{r}(t) = 4\cos t\,\mathbf{i}+4\sin t\,\mathbf{j}+t\,\mathbf{k}, \qquad 0\le t\le 4\pi$$ Projected onto the $xy$-plane this is a circle of radius $4$; the $z$-coordinate climbs steadily as $t$ increases, from $z=0$ up to $z=4\pi$ — tracing a helix (think spring, or a strand of DNA). One full turn of the circle ($t$ increasing by $2\pi$) raises $z$ by $2\pi$, so the helix completes exactly two full turns over $0\le t\le 4\pi$.
An Elliptical Helix
Replacing the circular cross-section by an ellipse ($x=4\cos t$, $y=3\sin t$) gives the same idea with an elliptical, rather than circular, cross-section: $$\mathbf{r}(t) = 4\cos t\,\mathbf{i}+3\sin t\,\mathbf{j}+t\,\mathbf{k}$$ Same construction as before — a plane curve in $x,y$, stretched upward at a constant rate by the $\mathbf{k}$-component — just with a non-circular base curve.
Limits of Vector-Valued Functions
Definition & Theorem 3.1
$\mathbf{r}(t)$ approaches limit $\mathbf{L}$ as $t\to a$, written $\lim_{t\to a}\mathbf{r}(t) = \mathbf{L}$, provided $$\lim_{t\to a}\|\mathbf{r}(t)-\mathbf{L}\|=0.$$ In practice we never use this directly — Theorem 3.1 says the limit is computed component by component: $$\lim_{t\to a}\mathbf{r}(t) = \Big[\lim_{t\to a}f(t)\Big]\mathbf{i}+\Big[\lim_{t\to a}g(t)\Big]\mathbf{j}+\Big[\lim_{t\to a}h(t)\Big]\mathbf{k}$$ provided the three limits on the right all exist.
Example 3.3
Evaluating the Limit of a Vector-Valued Function
$\displaystyle\lim_{t\to 3}\Big[(t^2-3t+4)\mathbf{i}+(4t+3)\mathbf{j}\Big] = $ \(4\mathbf{i}+15\mathbf{j}\)

$\displaystyle\lim_{t\to 3}\left[\frac{2t-4}{t+1}\,\mathbf{i}+\frac{t}{t^2+1}\,\mathbf{j}+(4t-3)\,\mathbf{k}\right] = $ \(\tfrac12\mathbf{i}+\tfrac{3}{10}\mathbf{j}+9\mathbf{k}\)
Continuity of Vector-Valued Functions
Definition
$\mathbf{r}(t)$ is continuous at $t=a$ provided all three of the following hold:
  • $\mathbf{r}(a)$ exists
  • $\lim_{t\to a}\mathbf{r}(t)$ exists
  • $\lim_{t\to a}\mathbf{r}(t) = \mathbf{r}(a)$
Just as with scalar functions, $\mathbf{r}$ is continuous at $t=a$ exactly when each component function $f$, $g$, $h$ is continuous at $t=a$.
Space Curves
Definition
The set of terminal points traced out by $\mathbf{r}(t)$ as $t$ ranges over its domain is called a plane curve (2D) or space curve (3D). Writing the components out as $$x=f(t), \qquad y=g(t), \qquad z=h(t)$$ gives the parametric equations of the curve — the same curve, described without vector notation. Every space curve above (the ellipse, the two helices) is really three ordinary parametric equations packaged into one vector-valued function.
