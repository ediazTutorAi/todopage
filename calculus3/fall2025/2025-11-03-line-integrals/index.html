Line Integrals

Scalar Line Integrals
Definition
Definition: scalar line integral

Let \(f\) be a function with a domain that includes the smooth curve \(C\) parameterized by \(\vec r(t)=\langle x(t),y(t),z(t)\rangle\), \(a\le t\le b\). The scalar line integral of \(f\) along \(C\) is

$$\int_C f(x,y,z)\,ds=\lim_{n\to\infty}\sum_{i=1}^{n} f(P_i^*)\,\Delta s_i$$

if this limit exists, where \(\Delta s_i\) is the length of the \(i\)th piece of \(C\) and \(P_i^*\) is a point in it.

Example 6.14. \(\int_C 2\,ds\), where \(C\) is the upper half of the unit circle.\(2\pi\)

Vector Line Integrals
Orientation and work
Orientation

A specified direction along \(C\) is an orientation; \(C\) is then an oriented curve. \(-C\) is the same curve with the opposite orientation. A closed curve has a parameterization with \(\vec r(a)=\vec r(b)\), traversed exactly once.

Definition: vector line integral
$$\int_C\vec F\cdot\mathbf T\,ds=\lim_{n\to\infty}\sum_{i=1}^n\vec F(P_i^*)\cdot\mathbf T(P_i^*)\,\Delta s_i$$

The work done by \(\vec F\) moving a particle in the positive direction along \(C\) is \(W=\int_C\vec F\cdot\mathbf T\,ds\).

Evaluating a Vector Line Integral
Equation 6.9
Equation 6.9
$$\int_C\vec F\cdot d\vec r=\int_C\vec F\cdot\mathbf T\,ds=\int_a^b\vec F(\vec r(t))\cdot\vec r^{\prime}(t)\,dt,\qquad \int_{-C}\vec F\cdot d\vec r=-\int_C\vec F\cdot d\vec r.$$

Example 6.19. The same field with \(\vec r(t)=\langle\cos(t+\pi),\sin t\rangle\), \(0\le t\le\pi\).\(-\pi\)

Piecewise Smooth Curves
Theorem 6.5
Piecewise smooth curve

\(C=C_1+C_2+\cdots+C_n\), smooth curves where the endpoint of \(C_i\) is the starting point of \(C_{i+1}\).

Theorem 6.5: Properties of Vector Line Integrals

i. \(\int_C(\vec F+\vec G)\cdot d\vec r=\int_C\vec F\cdot d\vec r+\int_C\vec G\cdot d\vec r\)   ii. \(\int_C k\vec F\cdot d\vec r=k\int_C\vec F\cdot d\vec r\)   iii. \(\int_{-C}\vec F\cdot d\vec r=-\int_C\vec F\cdot d\vec r\)

iv. \(\int_C\vec F\cdot d\vec r=\int_{C_1}\vec F\cdot d\vec r+\cdots+\int_{C_n}\vec F\cdot d\vec r\)

Example 6.21. \(\int_C\vec F\cdot d\vec r\), \(C\) the rectangle with vertices \((0,0),(2,0),(2,1),(0,1)\) counterclockwise, \(\vec F=\langle x-2y,\,y-x\rangle\).\(2-\tfrac32+2-\tfrac12=2\)
Checkpoint 6.19. \(\vec F=\langle y^2,\,2xy+1\rangle\), \(C\) the triangle \((0,0),(4,0),(0,5)\) counterclockwise.\(0+5-5=0\)

Flux Across a Curve
Definition, Theorem 6.6
Definition: flux

For \(\vec r(t)=\langle x(t),y(t)\rangle\), let \(\mathbf n(t)=\langle y'(t),-x'(t)\rangle\) (normal, pointing right of the direction of travel) and \(\mathbf N=\mathbf n/\|\mathbf n\|\). The flux of \(\vec F\) across \(C\) is \(\int_C\vec F\cdot\mathbf N\,ds\).

Theorem 6.6: Calculating Flux across a Curve
$$\int_C\vec F\cdot\mathbf N\,ds=\int_a^b\vec F(\vec r(t))\cdot\mathbf n(t)\,dt$$
