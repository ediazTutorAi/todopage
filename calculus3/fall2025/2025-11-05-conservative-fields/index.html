Conservative Vector Fields

Curves and Regions
Definitions
Definition: closed and simple curves

Curve \(C\) is a closed curve if there is a parameterization \(\mathbf r(t),\ a\le t\le b\) of \(C\) such that the parameterization traverses the curve exactly once and \(\mathbf r(a)=\mathbf r(b)\). Curve \(C\) is a simple curve if \(C\) does not cross itself.

Definition: connected and simply connected regions

A region \(D\) is a connected region if, for any two points \(P_1\) and \(P_2\), there is a path from \(P_1\) to \(P_2\) with a trace contained entirely inside \(D\). A region \(D\) is a simply connected region if \(D\) is connected and, for any simple closed curve \(C\) that lies inside \(D\), curve \(C\) can be shrunk continuously to a point while staying entirely inside \(D\). In two dimensions, a region is simply connected if it is connected and has no holes.

Fundamental Theorem for Line Integrals
Theorem 6.7
Theorem 6.7: The Fundamental Theorem for Line Integrals

Let \(C\) be a piecewise smooth curve with parameterization \(\mathbf r(t),\ a\le t\le b\). Let \(f\) be a function of two or three variables with first-order partial derivatives that exist and are continuous on \(C\). Then,

$$\int_C\nabla f\cdot d\mathbf r=f(\mathbf r(b))-f(\mathbf r(a)).$$
Example 6.28. \(\mathbf F(x,y)=\langle2x,4y\rangle\), \(C\) the segment from \((0,0)\) to \((2,2)\). Here \(f(x,y)=x^2+2y^2\).\(\displaystyle\int_0^1 24t\,dt=12=f(2,2)-f(0,0)\)

Path Independence
Theorems 6.8 and 6.9
Consequence: closed curves

If \(\mathbf F\) is conservative and \(C\) is a closed curve, then the circulation of \(\mathbf F\) along \(C\) is zero: \(\displaystyle\int_C\mathbf F\cdot d\mathbf r=0\).

Definition: independent of path

Let \(\mathbf F\) be a vector field with domain \(D\). The vector field \(\mathbf F\) is independent of path (or path independent) if \(\displaystyle\int_{C_1}\mathbf F\cdot d\mathbf r=\int_{C_2}\mathbf F\cdot d\mathbf r\) for any paths \(C_1\) and \(C_2\) in \(D\) with the same initial and terminal points.

Theorem 6.8: Path Independence of Conservative Fields

If \(\mathbf F\) is a conservative vector field, then \(\mathbf F\) is independent of path.

Theorem 6.9: The Path Independence Test for Conservative Fields

If \(\mathbf F\) is a continuous vector field that is independent of path and the domain \(D\) of \(\mathbf F\) is open and connected, then \(\mathbf F\) is conservative.

Finding a Potential Function
Strategy
Problem-Solving Strategy: Finding a Potential Function for \(\mathbf F(x,y)=\langle P(x,y),Q(x,y)\rangle\)
  1. Integrate \(P\) with respect to \(x\). This results in a function of the form \(g(x,y)+h(y)\), where \(h(y)\) is unknown.
  2. Take the partial derivative of \(g(x,y)+h(y)\) with respect to \(y\), which results in the function \(g_y(x,y)+h'(y)\).
  3. Use the equation \(g_y(x,y)+h'(y)=Q(x,y)\) to find \(h'(y)\).
  4. Integrate \(h'(y)\) to find \(h(y)\).
  5. Any function of the form \(f(x,y)=g(x,y)+h(y)+C\), where \(C\) is a constant, is a potential function for \(\mathbf F\).

Testing a Vector Field
Theorems 6.10 and 6.11
Theorem 6.10: The Cross-Partial Test for Conservative Fields

If \(\mathbf F=\langle P,Q,R\rangle\) is a vector field on an open, simply connected region \(D\) and \(P_y=Q_x\), \(P_z=R_x\), and \(Q_z=R_y\) throughout \(D\), then \(\mathbf F\) is conservative.

Theorem 6.11: Cross-Partial Property of Conservative Fields

Let \(\mathbf F=\langle P,Q,R\rangle\) be a vector field on an open, simply connected region \(D\). Then \(P_y=Q_x\), \(P_z=R_x\), and \(Q_z=R_y\) throughout \(D\) if and only if \(\mathbf F\) is conservative.

In \(\mathbb R^2\): \(\mathbf F=\langle P,Q\rangle\) on an open, simply connected domain is conservative if and only if \(P_y=Q_x\).

Example 6.34. Is \(\mathbf F(x,y,z)=\langle xy^2z,\,x^2yz,\,z^2\rangle\) conservative?no: \(Q_z=x^2y\), \(R_y=0\)
Example 6.35. Is \(\mathbf F(x,y)=\langle x\ln y,\,\tfrac{x^2}{2y}\rangle\) conservative? (domain \(y>0\)).yes: \(P_y=\tfrac xy=Q_x\), and \(y>0\) is simply connected
Checkpoint 6.31. Is \(\mathbf F(x,y)=\langle\sin x\cos y,\,\cos x\sin y\rangle\) conservative?yes: \(P_y=-\sin x\sin y=Q_x\)

Domain with a hole
A theorem is a tool

The Cross-Partial Property can be applied only if the domain of the vector field is simply connected. Consider

$$\mathbf F(x,y)=\frac{y}{x^2+y^2}\,\mathbf i+\frac{-x}{x^2+y^2}\,\mathbf j.$$
Check the cross-partials: \(\dfrac{\partial}{\partial y}\Big(\dfrac{y}{x^2+y^2}\Big)\) and \(\dfrac{\partial}{\partial x}\Big(\dfrac{-x}{x^2+y^2}\Big)\).both equal \(\dfrac{x^2-y^2}{(x^2+y^2)^2}\)
